## 1. 背景与定位

**为什么需要**：focus 16 只中 4 只为港股/中概标的（腾讯、美团、阿里、蜜雪）；[宏观边际变量追踪](../wiki/macro/宏观边际变量追踪.md) 已明确判定"港股远比 A 股脆弱：美元/美债/AI 三条线直接传导、无国内政策缓冲"，但目前 **没有港股侧的流动性专页**——A 股侧有 [两融追踪](../wiki/macro/A股两融余额追踪.md) 做杠杆水位计，港股侧对应的"水位计"缺位。

**定位**（对标两融页）：
- 新建 wiki 页 `wiki/macro/港股流动性追踪.md` = **regime 解读层 + 分层信号灯**，挂滚动窗口快照时间序列
- **周度节奏更新**（随 periodic-review 触发，复盘间隔 3-16 天不定，故所有"周"指标统一定义为**滚动 5 个交易日窗口（截至 T-1 收盘）**，由脚本自算、与复盘间隔解耦）
- **不做合成单一"流动性指数"**——卖方标杆（中金《港股流动性图景》系列）也是多指标并列呈现而非合成打分；合成指数不可解释、校准成本高
- 用途：① 港股/中概标的的风险背景输入（对接 [系统性风险防御](../wiki/strategies/系统性风险防御.md)）；② periodic-review 复盘时港股侧一句 regime 判断的数据底座；③ 宏观边际变量③（美元+美债）的港股传导细化

### 设计权衡（预先否决项）

| 候选 | 决策 | 原因 |
|---|---|---|
| 合成流动性指数（打分卡） | **否** | 不可解释；中金框架亦为多指标并列；分层信号灯已够用 |
| 依赖 daily-market 日采南向 | **否**（门1 修正） | daily-market 的南向采集已被用户砍掉（脚本零实现，行业级资金替代市场级）；本页南向自取日频历史序列，不得写成"复用已有" |
| 日频采集 job | **否** | HKMA 数据 T+1、regime 意义在周级变化；事件⚡用日序回扫补（§4.5） |
| EPFR 主动/被动外资流 | **否** | 付费数据不可自动化获取；用中金月度报告转述做定性补充 |
| CCASS 外资中介持股汇总 | **v1 否，backlog** | 披露易仅逐股查询，无汇总 API，工程量/收益比差 |
| 自算 AH 溢价（腾讯 AH 对成分加权） | **否** | 与官方 HSAHP 口径不可比，历史阈值失效 |
| 回购金额/IPO 募资进脚本 | **否** | 无稳定免费 API；降为 wiki 页月度定性段（periodic-review 顺手填） |

## 2. 指标体系（三层 9 项 + 2 项低频定性）

理论依据：中金《谁在主导港股行情——港股流动性图景》框架的指标优先级为 **ADT → 南向净流入 → 总结余/HIBOR → AH 溢价 → EPFR 外资**（[原文已核✅](https://finance.sina.com.cn/stock/marketresearch/2025-07-21/doc-infheqee5094050.shtml)）；叠加联汇制度传导链（利差→套息→汇率→兑换保证→总结余→HIBOR），三层结构如下。

### 2.1 货币面（港元贵不贵）——联汇制度传导链

| # | 指标 | 含义与信号方向 | 频率 |
|---|---|---|---|
| 1 | **HKMA 银行体系总结余** (Aggregate Balance) | 港元基础流动性水位，联汇制度下强/弱方兑换保证触发的结果变量。低位≈钱紧（HIBOR 对资金流出敏感），高位≈钱松 | 日（T+1） |
| 2 | **HIBOR**（隔夜 + 1M） | 港元资金成本；1M 是套息/房贷/股市融资的锚。历史：<1% 极宽（2025-05~07），>4% 紧缩（2023 钱荒 4.5%+） | 日 |
| 3 | **1M HIBOR − SOFR 利差** | 套息交易发动机。**符号约定全文统一：HIBOR−SOFR，负值=港元便宜=套息（借港元买美元）压力**。历史极值 **−350bp**（2025-06，弱方触发前夜，[已核✅](https://hk.finance.yahoo.com/news/7-85%E4%B8%8D%E9%81%A0%E4%BA%86-sofr-hibor%E5%88%A9%E5%B7%AE%E7%88%86%E8%A1%A8-%E5%A5%97%E5%88%A9%E4%BA%A4%E6%98%93%E7%8B%82%E8%BD%9F%E6%B8%AF%E5%85%83-074003625.html)），2022-23 周期约 −250bp。传导环：利差深负 → 套息流出 → 港汇贴弱方 → 弱方保证 → 金管局抽水 → HIBOR 回升自平衡。*口径注：1M HIBOR 对隔夜 SOFR 存在期限错配（vs 媒体常用 1M-1M），偏差 ±10-25bp，远小于 −200bp 阈值，可接受；runbook 声明* | 日 |
| 4 | **USD/HKD 区间位置** | (现价−7.75)/0.10 的百分位；贴 7.85 弱方 = 资金流出压力，贴 7.75 强方 = 流入。兑换保证触发的**传感器不是汇率而是 HKMA 日序 `market_activities` 字段**（非零=金管局出手，见 §4.5） | 实时 |

### 2.2 交易面（市场活不活）

| # | 指标 | 含义与信号方向 | 频率 |
|---|---|---|---|
| 5 | **主板成交额**（滚动 5 日均 + 月度官方 ADT 校准） | 交投温度计，南向+外资+本地合力结果。2023 ADT ~1,000 亿 [未核] → 2026-05 官方 2,929 亿（[HKEX✅](https://www.hkex.com.hk/Market-Data/Statistics/Consolidated-Reports/HKEX-Monthly-Market-Highlights?sc_lang=zh-HK)） | 日/月 |
| 6 | **卖空成交占比**（ex-ETP 主口径，全口径副记） | 空头/对冲情绪；HKEX 每日官方披露 | 日 |
| 7 | **VHSI 恒指波幅指数** | 港版 VIX。官方历史（[恒指 Factsheet✅](https://www.hsi.com.hk/static/uploads/contents/zh_cn/dl_centre/factsheets/volatilityindexc.pdf)）：2022 峰 49.4 / 2025 峰 47.0 / 十年区间 11.4-64.8 | 实时+历史 |

### 2.3 资金流 + 估值面（钱进不进、贵不贵）

| # | 指标 | 含义与信号方向 | 频率 |
|---|---|---|---|
| 8 | **南向净买入**（滚动 5 日累计 + YTD） | 港股定价权最大边际力量：2025H1 南向占成交已达 35%、日均 61.5 亿（[中金✅](https://finance.sina.com.cn/stock/marketresearch/2025-07-21/doc-infheqee5094050.shtml)，**期间口径 2025H1**，来源文 2025-07-21）。口径 = 沪+深`当日成交净买额`（**勿用"资金净流入"列，那是每日额度**）。数据自取日频历史序列（见 §3 #8），**不依赖 daily-market** | 日（T+1） |
| 9 | **恒生 AH 溢价指数** (HSAHP) | 两地估值差 = 南向的估值吸引力（**本页设计逻辑 [推算]**：溢价高 = 港股折价深 → 估值动能强；低 <125 = 相对优势收敛。~~中金"南向偏好在 AH 溢价较高时投资港股"~~ **L3 抓出研究简报引用失实**——中金原文未建立南向×AH 关系，其南向归因为内地"资金盛+资产荒"，主 agent 第三方 WebFetch 仲裁确认）。<125 档界取中金原文可核的**"分红税安排下 125% 平价隐性底"** ✅。**注意结构性漂移**：南向占比升至 35% 使 AH 中枢系统性下移（2025-09 低点 116.62 [未核]），故档位用滚动分位数而非死值（§4.6） | 实时 |
| 10 | IPO 募资 / 大额解禁（低频定性） | 一级市场抽血 vs 二级流动性 | 月，人工段 |
| 11 | 上市公司回购（低频定性） | 存量托底力量（腾讯等大票回购是港股独有支撑） | 月，人工段 |

> 学术微观指标（Amihud ILLIQ / bid-ask spread）不进本页：卖方市场层框架极少使用，信息与成交额/VHSI 高度重叠，且个股层流动性不是本页边界。

### 实测踩坑（已验证，写进脚本约束）

1. **HKMA API 的 `from`/`to` 参数不生效**——请求 `from=2021-01-01` 返回全史 6,274 条（至 2002）。翻页只能 `pagesize`(≤100)+`offset`。
2. **HKMA API 有脏数据**：2019 年某记录 `hibor_fixing_1m=199.29`（不可能值）。sanity 区间强制（HIBOR ∈ [0, 12]）。
3. **HKMA API 经本机代理明显慢/抖**（门1 评审 3 次调用 2 次 60s 超时；主 agent 全通）——P1 规格：timeout ≥ 60s + 重试 ≥ 2 次 + 失败走"未评级"路径（§4.7）。
4. **AH 溢价指数无腾讯/新浪源**（`hkHSAHP`/`rt_hkHSAHP` 实测空返回、新浪港股指数列表 38 个无 AH），东财 push2 是唯一实时免费源。
5. **dayquot 页 ~29MB**——脚本用流式正则只取 3 行，勿整页入库/入上下文；文件名 `d260630e.htm` = 日期 YYMMDD + e(英)/c(中)。
6. **港股节假日历 guard**：节假日无 dayquot 文件、HKMA 无记录（7/1 回归纪念日即例）——脚本按"文件/记录不存在且非周末 → 查前一交易日"处理，连续 **4** 个非周末日无数据才报错（农历新年可连休 3 个非周末日，阈值 3 会年年误报；门2 修）。
7. python `urllib` 走本机代理对 HKMA 会 SSL EOF，**必须用 `requests`**。
8. VHSI 官方 Factsheet 月更有滞后（5/29 值 19.15 vs 7/2 实时 23.77）——分位数用新浪历史序列本地算，Factsheet 只做月末校准。
9. macOS 无 `timeout` 命令（脚本内用 requests timeout 参数控制，不依赖 shell）。

## 4. 信号灯与阈值

> 门1 重构：**每层一个主变量、穷尽分档定灯**（任何读数必落且仅落一档）；第二变量降为**修饰标签**（不定灯）；跨子读数碰撞一律**取紧优先**（🔴>🟠>🟡>🟢）。标 ⚙ 的初值待 4-8 周实跑后按 §4.6 校准。

### 4.1 货币面灯（两个子读数各自分档，取紧合成）

| 子读数 | 🟢 | 🟡 | 🔴 |
|---|---|---|---|
| 总结余 | >800 亿 | 500-800 亿 | <500 亿（贴 2023/2024/2025 三次地板 445-446 亿，日频收盘口径） |
| 1M HIBOR | <1.5% | 1.5-4% | >4%（2023 钱荒式） |

**灯 = 两者取紧**。历史回测自检：2023 钱荒（445 亿, 5.66%）→🔴✓；2025-05~07 注资极宽（1,700 亿, 0.5-1%）→🟢✓；**2022H2 加息抽水（结余 961-3,775 亿但 1M 冲 5.08%）→取紧=🔴✓**（原"或"逻辑会双灯并亮，已修）；当前（540 亿, 2.94%）→🟡✓。

修饰标签：利差 < −200bp 标"套息压力积累"（2025-06 极值 −350bp）；USD/HKD 区间位置 ≥90% 标"贴弱方"、≤10% 标"贴强方"。

### 4.2 交易面灯（主变量 = 滚动 5 日均成交，穷尽分档）

| 灯 | 滚动 5 日均成交 ⚙ |
|---|---|
| 🔴 缩量 | <1,500 亿 |
| 🟡 清淡 | 1,500-2,200 亿 |
| 🟢 常态-活跃 | 2,200-3,500 亿（2026-04/05 官方 ADT 2,535/2,929 亿在此档） |
| 🟠 放量 | >3,500 亿——性质由 VHSI 标签定名：**放量+VHSI<20 = "放量自满"（顶部形态⚡）；放量+VHSI>35 = "放量恐慌"（2025-04 关税崩盘式⚡）** |

修饰标签：VHSI >35 恐慌 / 30-35 紧张 / <20 自满（跨 30 是 2022/2024/2025 三轮急跌公共阈值）；卖空占比 ex-ETP >18% 空压高 / <10% 空头收缩 ⚙。

### 4.3 资金流+估值面灯（主变量 = 南向滚动 5 日净买，穷尽分档）

| 灯 | 南向滚动 5 日净买 ⚙ |
|---|---|
| 🔴 流出 | < −200 亿，**或连续 2 个窗口 < 0**（防单窗频闪——2025 纪录年也有负周） |
| 🟡 弱/中性 | −200 ~ +100 亿 |
| 🟢 流入 | +100 ~ +300 亿 |
| 🟢⁺ 强流入 | > +300 亿（2025H1 日均 61.5 亿 × 5 的量级） |

修饰标签（AH 不定灯）：AH >150 "折价深-南向动能支撑" / 135-150 中枢 / <125 "估值吸引力弱化"。

### 4.5 事件⚡（回溯口径，非实时告警）

**传感器 = 周度脚本每次运行时回扫上次快照以来的日频序列**（HKMA 日序 + 南向 EM 日序），逐日判定、在快照"本窗口内事件"块补记：

| ⚡事件 | 传感器 |
|---|---|
| 强/弱方兑换保证触发（金管局注资/抽水） | HKMA 日序 `market_activities` ≠ 0（比盯汇率更准——这是官方干预记录本身） |
| 南向单日 \|净买\| > 100 亿 | EM 日序回扫 |
| 1M HIBOR 单日变动 > 50bp | HKMA 日序回扫 |
| AH 上穿 150 / 下穿 120；VHSI 上穿 35 | 快照时点值判定（AH 无可靠免费日序，标"时点口径"） |

**明示局限**：⚡为回溯发现（滞后至多一个复盘间隔），不是实时告警。若未来需要日级发现，须由用户决策是否在 daily-market job 增加 2-3 个只记数字段（南向/AH/港汇）——**该项与用户此前"砍掉市场级资金采集"的决策相抵，默认不做，此处仅登记为待决项**。

### 4.6 阈值校准方法（⚙ 项）

- 绝对档位会被结构性漂移打烂（南向占比 3 年从 ~15% → 35%、ADT 3 年翻 3 倍、AH 中枢下移），**⚙ 项校准一律改"滚动 52 周分位数带"**：成交/南向/卖空/VHSI 各自算 P20/P50/P80，档位边界 = 分位数值四舍五入到整百，每季度重算一次（periodic-review 季度节点顺手跑）。
- 首跑即出分位数（成交/VHSI/南向历史序列均可回拉 ≥1 年）；上表初值为"分位数未跑前的占位"，P3 完成首次校准后本表以脚本输出为准。
- 货币面（结余/HIBOR）**不用分位数**——联汇制度下这两个量的经济含义是绝对的（地板 445 亿、钱荒 4%+），保持事件锚定死值。

### 4.7 缺数处理（禁止静默错灯）

- 任一层的主变量缺失或新鲜度超限（数据日期距今 >5 个交易日）→ 该层灯输出 **"未评级（缺 X，最后有效值 YYYY-MM-DD）"**，**禁止用 stale 值机械套档**（AH 的 Factsheet 回退值只作参考注记，不参与标签判定）。
- 快照顶部强制"⚠️ 缺数清单"行（学 daily-market 的校验警示行），无缺数时写"✓ 9/9"。
- 修饰标签的输入缺失 → 该标签省略并入缺数清单，不影响主灯。

## 6. 数据纪律映射（门1 修正：分级，不搞"API 即观测"一刀切）

- **高时效红线适用**：港汇/HIBOR-SOFR 直接挂"美联储利率/汇率"红线（[data-discipline §C](data-discipline.md)）→ 本页数字更新**不豁免，L1/L2/L3 全跑**。
- **[观测] 分级**：
  - **canonical 直取 = [观测]**：HKMA / NY Fed / HKEX dayquot（#1/2/3/5/6）——API/页面即原始发布渠道，raw JSON 记录完整请求 URL + 时间戳供 L3 复调（两融页"akshare 直取 [观测]"先例的同等待遇）。
  - **转发源 = [观测·转发源]**：新浪 USDHKD（#4）、腾讯 VHSI（#7）、EM 南向/AH（#8/9）——**不得自动继承 canonical 待遇**，强制配官方校准节奏（§5：月末 Factsheet/HKEX 月报/Stock Connect 官方页），校准偏差 >1% 记入 wiki 页"数据获取"节并修正主源用法。
- **L2 阶段 A 等价关系（明示，防话术滑过）**：周度更新时，脚本打印进复盘对话的快照表（含逐项源 URL 与校验标记）**即是**"对话内可见的数据声明清单"；主 agent 仍须对表中数字执行阶段 B 核对（canonical 项 = 复调 API；转发源项 = 与校准源核对），**"脚本已校验"不构成跳过阶段 A/B 的理由**。
- **[推算] 项**：利差 = 两个 [观测] 相减、区间位置 = 公式，按 L2 列公式反推。
- **建页首版**是大额历史数字写入（§8 锚点入 wiki"关键历史节点"表）→ 完整 L1→L2→L3，[未核] 项要么补 WebFetch 核实要么降档标注后入页。
- **周度追加**通常 >2 处数字且踩红线 → L3 照跑（sonnet 档）。
