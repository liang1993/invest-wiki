# 2026年5月份70个大中城市商品住宅销售价格变动情况

## 关键数据（原文已验证，fetch.py 核对）

**新建商品住宅：**
- 环比：一线 **+0.2%**（涨幅扩大 0.1pct，沪/穗 +0.2% / 深 +0.4% / 京 -0.2%）/ 二线 -0.1% / 三线 -0.4%（扩大 0.1pct）
- 同比：一线 -1.7%（收窄 0.4pct，**沪 +3.2% 为 70 城唯一正** / 京 -2.1% / 穗 -3.3% / 深 -4.5%）/ 二线 -3.2% / 三线 -4.2%
- 新建环比上涨城市 16 个（比上月增 2 个）

**二手住宅：**
- 环比：一线 +0.4%（京 +0.1% / 沪 +0.6% / 穗 +0.1% / 深 +0.6%）/ 二线 -0.2% / 三线 -0.4%
- 同比：一线 -5.8%（京 -6.5% / 沪 -4.3% / 穗、深更深）/ 二三线降幅总体收窄

官方定性："5 月份一二三线城市商品住宅销售价格同比降幅总体收窄"

## 判读要点
- 政策托一线 + 低基数的结构性局部回暖，非全面见底——一线（尤其上海）撑住、二手同比仍深跌、二三线持续下行；与投资/新开工 -16%/-22% 深跌并存。
