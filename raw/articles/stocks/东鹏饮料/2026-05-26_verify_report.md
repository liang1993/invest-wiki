## 一、Fail 项（强制修订）

### F1：销售额 vs 销量口径错误
- **wiki 写的**：「一句话」「投资逻辑」"东鹏特饮 2024 销售额超红牛中国，能量饮料 No.1"
- **正确值**：东鹏 2024 能量饮料收入 133.04 亿；红牛中国 210.9 亿（华彬）；东鹏 No.1 的口径是**销售量**（份额 47.9% vs 红牛约 31%），不是销售额
- **置信度**：[观测] 新浪财经 2025-03-11、21 经济网 2025-08-19
- **影响**：核心多空叙事基石错误。"销售额超红牛"是 wiki 第二条投资逻辑的强叙事
- **主 agent 仲裁结论**：✅ 采纳，独立 WebFetch 新浪原文已确认

### F2：H 股破发跌幅 30% vs 实际 23%
- **wiki 写的**："H 股 2026-02 上市破发，跌 30%"
- **正确值**：2026-02-03 发行价 248 港元，**首日收盘 251.8 港元 +1.53%（未破发）**；4 月 13 日盘中创低 190.2 港元，跌 **-23%**
- **置信度**：[观测] 21 经济网 + 东方财富 2026-04-20
- **影响**：跌幅夸大导致"市场过度悲观"叙事过强
- **主 agent 仲裁结论**：✅ 采纳

### F3：PE 18.4x vs 21.7x 口径混用未标注
- **wiki 写的**：「结论速览」21.7x、「同行对比」18.4x、「预期差 5.1」18.4x、「市场定价 5.4」21.7x
- **正确值**：两个数本身都对（18.4x = 138.69/7.60 远期 PE；21.7x = 138.69/6.42 TTM PE），但同一份 wiki 在不同章节切换口径而不标注
- **置信度**：[推算]
- **影响**：预期差判定的依据被污染
- **主 agent 仲裁结论**：✅ 采纳，全文统一标注口径

### F4：分业务加总数学错误
- **wiki 写的**：176.3 + 52.4 + 36.0 = 254.7
- **正确值**：176.3 + 52.4 + 36.0 = **264.7**（差 10 亿，约 4%）
- **置信度**：[推算] 加法
- **影响**：子项与合计需自洽，且与一致预期 254 亿匹配口径需选择
- **主 agent 仲裁结论**：✅ 采纳，调整子项贴合 254 亿一致预期：电解质 +50%（49.2）+ 其他 +45%（29.0），合计 254.5

### F5：林氏家族持股 50%+ vs 实际 67.71%
- **wiki 写的**："林氏家族集中控股 50%+"
- **正确值**：**67.71%**（林木勤 49.74% + 林煜鹏 6.44% + 林木港 5.22% + 林戴钦 5.22% + 陈海明 1.09%）
- **置信度**：[观测] 新浪财经 2025-10-16
- **影响**：家族化程度的关键事实
- **主 agent 仲裁结论**：✅ 采纳，独立 WebFetch 已确认

### F6：红牛中国份额 36% = 华彬 + 天丝合计 概念错误
- **wiki 写的**："红牛中国 ~36%（华彬泰国天丝合计）"
- **正确值**：华彬红牛与泰国天丝是商标官司双方，不能称"合计"。2024 销售额份额分别约 华彬 31% / 泰国天丝 13.84%
- **置信度**：[观测] 新浪财经 2025-03-11
- **主 agent 仲裁结论**：✅ 采纳，分列两家
