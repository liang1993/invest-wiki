# 中芯国际 0981.HK 港股估值重跑独立校验报告

## 校验范围

- 核心估值链：归母权益、总股本、汇率、BVPS、当前 PB 与四档锚点。
- 业务与质化覆盖：收入结构、竞争格局、同行估值、交易影响、管理层与研发团队。
- 跨文件一致性：个股页、价格区间总览、索引和半导体行业页仅保留 0981.HK 的价格与估值口径。

## 首轮独立校验

首轮扫描 19 组项目，结果为 **11 Pass / 5 Warning / 3 Fail**。

### 已通过的核心数据

- Q2 归母权益 US$25,149.484m、总股本 8,560.81m 股及分母选择正确。
- `25,149.484 ÷ 8,560.81 = US$2.93775`；经当日 USD/HKD 7.84669 末端换算，BVPS 为 HK$23.0516。
- 2026-08-13 收盘 HK$67.55；`67.55 ÷ 23.0516 = 2.9304x`。
- 加权 PB 为 `2.55×70% + 1.998×30% = 2.3844x`，对应 HK$54.96，展示合理价值 HK$55。
- 港股历史 PB 的 20 分位、中位和 80 分位分别为 0.876x、1.998x、3.328x；价格反推正确。
- Q2 财务、产能、利润质量、现金流与五年趋势数据通过原文或接口复核。

### 首轮问题及主 agent 仲裁

1. **合理价值口径未解释**：确认属展示问题。已明确精确加权值 HK$54.96 与四档执行模型点 2.4x / HK$55.32 的用途，整数锚点不变。
2. **数字三档标签不完整**：确认。已为估值、财务、产能、五年趋势及派生比例补 `[观测]`、`[推算]`、`[估计]`。
3. **历史 PB 原页复取受限**：校验员遇页面限流；主 agent 已在写入前读取原页核对三项分位，保留观测日期和本地归档，本项关闭。
4. **“2025 年后估值中枢明显抬升”证据不足**：确认并删除，不以强化叙事替代时序证据。
5. **6 月交易解释不足**：确认。补充收购中芯北方剩余 49%、新增 547,182,073 股及归母权益变化机制；不引用另一市场发行价格。
6. **漏报 5.4% 其他服务**：确认。补充晶圆制造 94.6%、其他 5.4%，并注明公司未进一步拆分“其他”。
7. **竞争与同行估值不足**：确认。补充 TrendForce 全球份额和中银国际同行 PB/ROE 对照。
8. **治理与技术团队不足**：确认。补充董事长、联合 CEO、任职起点、技术履历、长期激励、员工及研发人员数据。

## 第二轮定向复核

第二轮对上述八项逐项检查，六项关闭，剩余 **1 Warning / 1 Fail**：既有财务表的三档标签仍不完整；治理部分仍缺任职稳定性、技术履历及研发团队量化数据。

主 agent 回读 2025 年报原文后补充：两位联合 CEO 均自 2017-10-16 起任职；赵海军拥有逾 30 年行业经验，梁孟松拥有逾 40 年经验、逾 450 项专利和 350 余篇论文；2025 年末员工 19,952 人，其中研发人员 2,403 人、占 12.0%。同时补齐表级观测标签和派生数字推算标签。

## 最终结论

最终定向复核结果：

- 三档标签：Pass。
- 治理与技术执行：Pass。
- 单一港股口径：Pass；未发现中芯国际另一市场价格、代码、估值或跨市场价差残留。
- **合计：3 Pass / 0 Warning / 0 Fail（0✗0⚠️）**。
