# 常用数据与口径：她盯哪些分项

把"艾丽盯的分项"对接到 [`macro-analysis`](../../macro-analysis/SKILL.md) 的 akshare 取数函数——取数走 macro-analysis，本表告诉你**取来之后该看哪些细项、怎么拆**。她的招牌动作是"逐项拆结构"，所以每个指标都要下沉到分项。

> 数据源接口的排序方向（倒序/正序）、已知不可用接口见 macro-analysis 速查表，不在此重复。

## 国内核心指标

| 指标 | 她的来源 | macro-analysis 函数 | 她必拆的分项 |
|---|---|---|---|
| 社会消费品零售 | 统计局 | `macro_china_consumer_goods_retail()` | 分品类（金银珠宝/汽车/家电/建材家具/餐饮/烟酒/通讯/化妆品）；**限额以上 vs 整体**（看是否消费降级）；商品零售 vs 餐饮（服务韧性） |
| 社融/信贷 | 央行 | `macro_china_new_financial_credit()` / `macro_rmb_loan()` / `macro_rmb_deposit()`（社融 `shrzgm` 接口不可用） | 住户端（短期/中长期，看消费与房贷意愿）；企事业（短期=日常开支/中长期=投资扩产/**票据=冲量水分**）；存款（住户/非银，看"存款搬家"） |
| 固定资产投资 | 统计局 | `macro_china_gdzctz()` | **房地产内 vs 外**（扣地产后多少）；民间固投（民企信心）；外商港澳台；两重建设（信息传输/水上航空等新动能） |
| 工业增加值 | 统计局 | `macro_china_gyzjz()`（正序！） | 分行业：新动能（计算机通讯/集成电路/工业机器人/汽车/船舶航空）vs 旧动能（水泥/非金属矿物）；出口交货值 |
| 房地产 | 统计局 | `macro_china_real_estate()` / `macro_china_new_house_price()` | 开发投资、新房销售面积/额（价跌量缩）、70 城房价（一/二/三线 + 二手房同比降幅收窄否）、房企资金到位（资金压力） |
| CPI / PPI | 统计局 | `macro_china_cpi()` / `macro_china_ppi()` | **输入性通胀**视角（能源→成本→PPI→利润）；汽车等核心品类价格 |
| 进出口 | 海关 | `macro_china_hgjck()` | 出口：机电/集成电路（量价拆分，"更赚钱了"）/高新/汽车（以价换量）/稀土（监管+单价）；进口：原油（量价、缺口、霍尔木兹）/天然气/化肥/集成电路/半导体设备 |
| 财政收支 | 财政部 | `macro_china_czsr()` / `macro_china_national_tax_receipts()` | 增值税/企业所得税（新动能贡献）vs 契税/土增税/**卖地收入**（地产拖累）；广义财政收支差；出口退税、关税 |
| 失业率 | 统计局 | `macro_china_urban_unemployment()` | **分年龄组**（尤其 25-29 岁）；灵活就业口径影响 |
| LPR / 准备金 / 净息差 | 央行 | `macro_china_lpr()` / `macro_china_reserve_requirement_ratio()` | 降息空间受**净息差**（已约 1.4%，2021 年约 2%）约束 |
| 汽车销量 | 乘联会 | （不在 macro-analysis，需另取） | 新能源/燃油分化、零售 vs 出口、连续下降月数 |

## 海外 / 货币

| 主题 | 函数 | 她的视角 |
|---|---|---|
| 美联储利率 | `macro_bank_usa_interest_rate()` | 人事=信号（沃什+贝森特）；缩表；新美元体系 2.0 |
| 黄金/原油 | （`macro_cons_gold` 是 ETF 持仓非金价，金价/油价需另取） | **蓄水池逻辑**：不单看供需，看美元体系调节；大宗是"玩家的游戏" |
| 加密 / 稳定币 | —（需另取） | USDT/Tether 持美债体量、香港稳定币试验；"挂钩能源→上链→影子石油美元"，底座仍是美元 |
| 人民币国际化 | — | SWIFT/CIPS/mBridge 三层、货币互换、金融版北约；石油美元的对手盘 |

## 她常引的"权威锚"

解读时她爱引官方信源给判断背书，可在解读中适度模仿（引用须按 wiki 数据纪律核证）：

- **央行货币政策执行报告**（如"输入性通胀"提法）
- **经济日报 / 求是杂志**（如"黄金已成风险资产""居民增收计划"）
- **统计局/海关/财政部当月发布稿**

## 与 wiki 数据纪律的衔接

本 skill 产出若**回写 wiki**（如更新宏观仪表盘、写解读到 macro/ 页面），所有具体数字仍须走 CLAUDE.md 的 L1→L2→L3 数据写入纪律——口语化解读不豁免数字核证。日常对话式解读（不落 wiki）则不触发归档。
