# 估值方法库 — 第十刀的四种武器

快刀斩股的估值不是一招打天下，而是**按公司类型分类匹配**。这是他第十刀"最后一招"的真正内容。下面每种给公式 + 他的原话 + 逐字稿里的实算例子。

> 例子数字摘自 ASR 逐字稿，用于示范算法，非经核实的公司事实。

---

## 1. 市赚率 PR —— 稳定盈利股的主武器（段永平法）

**他最常用、也最招牌的估值法**，明确归功段永平："这个方法是段永平发明的，这里向大佬致敬。"

**公式**：
```
市赚率 PR = 真实市盈率 ÷ ROE(百分数的数值)
真实市盈率 = 真实收购成本 ÷ 预计净利润
真实收购成本 = 总市值 − 账面现金 + 有息负债
预计净利润 = 去年净利润 × (1 + 一季报同比增速) 外推全年
```

**判读档位**：
| 市赚率 | 含义 |
|---|---|
| < 1 | 黄金坑 |
| 1 ~ 1.5 | 估值合理 |
| > 1.5 | 没什么性价比 |

**两个关键讲究**（他每次都强调）：
1. **不用交易软件的 PE**，要用**兼并收购视角的真实收购成本**口径——"从兼并收购的角度出发，算出公司的真实收购成本"。所以要把账面现金减掉、把有息负债加回。
2. **用前瞻净利润**，不是去年的——拿一季报同比增速外推全年。

**实算例（宁德时代第 71 期）**："总市值 1.96 万亿，减去账面现金 4124 亿，再加上有息负债 997 亿，剩下的 16473 亿就是实际收购成本。2025 年净利润 722 亿，一季度同比增长 48.52%，推算 2026 全年约 1072 亿。16473 ÷ 1072 = 真实市盈率 15.37 倍，而不是软件显示的 24.84 倍。15.37 ÷ ROE 27.15 = 市赚率 0.57 倍，相当有吸引力。"

适用：盈利稳定、ROE 稳定的白马成长股（宁德、盐津）。

## 2. 历史市净率分位 —— 稳健白马 / 重资产

业绩稳健、资产质量稳定的公司，他不算市赚率，直接看**当前 PB 在自身历史区间的位置**。

**逻辑**："公司本身业绩稳健，资产质量稳定，所以完全可以参考过去几年的历史市净率，看公司当前的估值处在什么水平。"

**实算例（中国移动第 73 期）**："最近股价连续下跌，公司市净率只剩下 1.5 倍左右，几乎处于最近 3 年的最低位，可以说是相当合理。"

适用：重资产、业绩波动小、ROE 不高但稳定的标的（运营商、公用事业）。

> 配套认知——**市净率 = 资产质量溢价**："所谓的市净率其实就是市场对上市公司资产质量所支付的溢价。理论上讲，资产质量越高，市净率就越高。" 用这条抓**错杀**：紫金矿业"资产质量几乎是同业最高，可是市净率却几乎是最低的"→ 错配 → "也难怪公司最近又在大手笔回购股份了"。

## 3. 双腰斩理论 —— 超跌优质赛道股抄底（自创）

针对"基本面没坏但股价被错杀"的优质公司。

**定义**："一家优秀的上市公司，其股价经历两次腰斩，也就是下跌 75% 后，基本就是历史大底，随后将逐渐价值回归。"

**用法**：确认①公司是优质资产（前面九刀过关）②基本面无重大恶化③股价较高点累计跌幅 ≈ 75%，再叠加 PB 处历史低位 → 判"机遇大于风险"。

**实算例（爱尔眼科第 68 期）**："最高点 42.25 元，到 2026 年 3 月 27 日最低 9.32 元，累计跌幅 78%，在基本面没有重大变化的前提下，股价实现双腰斩……与此同时，市净率跌至 10 年最低点。由此可以大致得出结论，在当下这个位置，公司机遇大于风险。"

> ⚠️ 这是经验法则不是定律——"跌 75% 就是底"没有理论支撑，前提是"基本面没坏"这个判断要靠前九刀立住。模仿其口吻可用，别当铁律。

## 4. 周期股估值 —— 不看 ROE，看周期位置（京东方第 74 期）

周期股利润大起大落，他明确**跳过 ROE**、也不套市赚率：
- 先用利润波峰定**行业周期长度**（京东方"4 年一周期"）。
- 看资产负债表（烧钱程度）、在手订单（预收 + 合同负债同增 = 景气回升）、供给侧变化（"三星、LG 关停低效产能，面板行业再次迎来春天"）。
- 落点看是否"周期反转 + 不是虚空造牌"，而非给精确估值。

适用：面板、化工、航运、资源等强周期行业。

---

## 选型速查

| 公司类型 | 用哪把刀 |
|---|---|
| 盈利稳定 + ROE 稳定（白马成长） | 市赚率 PR |
| 稳健白马 / 重资产 / ROE 不高但稳 | 历史 PB 分位 |
| 优质但深跌（基本面没坏） | 双腰斩理论 + PB 历史低位 |
| 强周期股 | 不看 ROE，看周期位置 + PB + 在手订单 |
| 资源股（涨价 + 增产逻辑） | 生意本质（涨价属性 × 产能增长）+ PB 对标同业找错杀 |

> 所有估值法都服务于他的总信条："基本面分析并不能预测股价。" 估值给的是"贵不贵 / 性价比"，不是"会不会涨"。
