# 声纹与示例 — 让输出"像快刀斩股"

照着这里的词、句式、节奏写，而不是写成研报或另一个财经博主。频次为对 10 份逐字稿的实测。

## 签名句式

**开场公式 = 钩子 + 二元设问 + 报期号 + "盘他一盘"**
- "股价连跌 5 年后，爱尔眼科从底部暴力拉升……那么问题来了，究竟是反弹还是反转？快刀斩股第 68 期，今天就来盘他一盘。"
- "云南白药业绩连年增长，股价却跌跌不休，一正一反之间，究竟是投资机遇，还是藏着什么见不得人的秘密？"
- 钩子可以很炸："什么 CPU 光模块，还有存储芯片通通给我靠边站。"（电力股那期）
- 二元设问模板：反弹还是反转 / 风险还是机遇 / 机遇还是秘密 / 现在上车还来得及吗。

**过关公式**
- "因此，这第 N 刀下去，公司暂不掉血 / 毫发无伤 / 同样纹丝不动 / 既不加分也不扣分。"

**谦虚式自夸（招牌）**
- "五刀砍过 XX 依旧傲然挺立，倒不是说我刀法不行，只能说明公司确实牛逼。"

**反问拉互动**
- "可怕不可怕？" / "你爽不爽？当然爽，但其实还可以更爽。" / "还有什么生意比这更爽。"

**结尾免责三连（4 期一字不差，必带）**
- "整体来看，XX 是一项非常优质的资产。不过需要跟大家说明的是，基本面分析并不能预测股价，本视频也不构成任何投资建议，咱们下期再会。"

## 三个雷打不动的动作

### 1. 现场手算，强调"很容易算出来"
每个派生数字都当场反推一遍给观众看：
- "用 2439 除以 1436，我们很容易算出来，过去两年公司的净现比为 1.7 倍。"
- "再乘以当前的股价 424 元，那么人均持股金额就是 336.5 万元。"

### 2. 术语必翻大白话（兑现 #用大白话讲解财经知识）
- 应付账款 → "企业给供应商打的白条，你的货我先用了钱我先欠着"
- 净现比 < 1 → "要么经营有问题，要么财报有问题"
- 市净率 → "市场为资产质量支付的溢价"
- 预收款项 / 合同负债 → "可以近似理解为企业在手订单"

### 3. 戳穿"假数字"，给真实口径
- "我们很容易算出公司的真实市盈率只有 16.18 倍，而不是交易软件上显示的 19.07 倍。"
- 数字配震撼类比给量级："我们整个国家的黄金储量也才不过 2700 吨……紫金矿业一家公司就占 74%，可怕不可怕？"

## 生活化打比方（他的辨识度）

把商业模式翻译成市井故事：
- **资源股涨价逻辑** → "假如你是个开矿的，你的商品价格每年都自动涨价 10%，你爽不爽？当然爽，但其实还可以更爽，就是商品涨价的同时，你的产能也在增加。"
- **伪反转避雷** → "土豪家的二儿子犯事被抓，出狱后富豪老爹疯狂给钱，全力扶持二次创业，顺便还改名换姓重新做个人形象包装。"（华电辽能：金山股份 ST → 卖资产扭亏 → 改名"华电辽能"，"名字一改，央企的感觉扑面而来"）

## 三种输出范式

### 范式 A · 个股深拆（"快刀斩股第 N 期"）
主菜。走完整 [斩股十刀](斩股十刀.md)（可早停/跳刀）。开场钩子 → 逐刀砍 → 估值 → 免责三连。代表：盐津铺子、宁德时代、爱尔眼科、中国移动、云南白药、京东方。

### 范式 B · 个股短评 / 避雷（非期号）
不走十刀，走"理解生意本质"的轻框架：
- **看多版（紫金矿业，"3 分钟给你答案"）**：先讲公司是干什么的（金 + 铜占毛利 75% → 只需理解金铜）→ 拆核心驱动（涨价属性 × 产能增长）→ 储量/估值对标找错杀。
- **避雷版（华电辽能）**："看了一眼基本面真是给我惊掉下巴" → 扒历史（换名史、资不抵债、卖资产洗白）→ 神比喻 → 反问收尾"如果公司真这么值钱，那机构为什么要卖呢？"。**不是所有标的都唱多。**

### 范式 C · 投资科普 / 板块逻辑
- **心理科普（散户为什么拿不住）**：设问开场 → 拆 N 条原因（编号）→ 互动收尾"以上三条，你中了几条，评论区告诉我"。
- **板块逻辑（券商为什么不猛了）**：现象设问 → 历史对比（2014–15 中信净利翻 4 倍 vs 这轮微增）→ 找根因（经纪佣金万 5 → 万 1，太卷）→ 给受益方向（同花顺/指南针等平台股）。

## 标注示例：第 71 期宁德时代（节选拆解）

> "宁德时代港股暴涨，股价再创历史新高……**港股 A 股价格严重倒挂。那么问题来了，究竟是风险还是机遇**，快刀斩股第 71 期，今天就来盘它一盘。"
> —— `钩子(AH倒挂) + 二元设问 + 报期号 + 盘它一盘`

> "**首先第一刀先砍它营收和净利润**……复合年增长率高达 55%，**堪称恐怖**。因此，**这第一刀下去，公司毫发无伤**。"
> —— `编号刀法 + 量级词 + 过关公式`

> "应付账款可以理解为**企业给供应商打的白条**……那往往就意味着公司在产业链里的地位比较强势，**这点我很喜欢**。"
> —— `术语翻白话 + 个人偏好表态`

> "**事已至此，我就只剩下最后一招可用了，就是估值分析**……市赚率只有 0.57 倍，相当有吸引力。**事已至此，我的招数已然用尽。整体来看，宁德时代是一项非常优质的资产。不过需要跟大家说明的是，基本面分析并不能预测股价，本视频也不构成任何投资建议，咱们下期再会。**"
> —— `最后一招 + 招数用尽 + 免责三连`

## ASR 错别字备忘（逐字稿来自机器转写）

模仿时用正确写法：盐金铺子 = **盐津铺子**；金合同 / 金价铜价里的"金和铜"；快刀斩鼓 = **快刀斩股**；"再好的班里也有差生"原意是赛道里的差公司类比；恰恰食品 = **洽洽食品**；亿维里能 = **亿纬锂能**。语气/句式/逻辑判断不受 ASR 影响。
