# 斩股十刀 — 快刀斩股的招牌财报体检流水线

这是他整个人设的骨架：把一次枯燥的财报审计，包装成一套编号固定的武侠刀法。动词全程用"砍"，每过一关"傲然挺立 / 暂不掉血"，刀与刀之间用"既然如此，咱们第 N 刀跟上"衔接。**前五刀是财务体检（排雷），第六刀起"进入深水区"做基本面/筹码/估值。**

> 他自己在第 72 期云南白药里点过题：新书《快刀斩股》"里面详细介绍了斩股十刀每一刀的用法，同时也附带了我个人的完整交易体系"。所以"十刀"是他官方命名的体系，不是我们归纳的。

> **关于例子里的数字**：下文括号里的具体数字（ROE、净现比、市赚率等）均摘自他视频的 ASR 逐字稿，用来示范"他这一刀怎么砍、阈值卡在哪"，**是方法示范不是经核实的公司事实**（ASR 可能有误差）。真要给某只股写 wiki 估值，走 `value-invest` 并按数据纪律核数。

## 总览：十刀顺序与判语

| 刀 | 砍什么 | 核心判定 | 过关话术 |
|---|---|---|---|
| 第一刀 | 营收 + 净利润 | 是否"连续 N 年正增长，画出一条完美的上升曲线" | 毫发无伤 / 暂不掉血 |
| 第二刀 | 净资产收益率 ROE | 历年 ROE 水平（按行业放宽）；**周期股跳过** | 依然牛逼 / 纹丝不动 |
| 第三刀 | 资产负债表 | 现金 vs 有息负债；应收 vs 应付（产业链地位） | 没有偿债压力 |
| 第四刀 | 现金流量表 | 净现比 ≥ 1（"检查公司质量的神器"） | 暂不掉血 |
| 第五刀 | 股东回报 / 分红 | 连续分红年数 + 股利支付率 + 股息率（试金石） | 傲然挺立 |
| 第六刀 | 赛道分析 | 行业逻辑、空间、长期需求驱动（"进入深水区"） | — |
| 第七刀 | 同行对比 | 三率（毛利率/净利率/ROE）逐项排名 | 遥遥领先 / 拔得头筹 |
| 第八刀 | 股权变动 | 回购/增持（加分）vs 减持（扣分） | 既不加分也不扣分 |
| 第九刀 | 人均持股 | 剔除前十大后散户人均持股金额 vs 20 万门槛 | 主力介入深 / 掉血三低 |
| 第十刀 | 估值分析 | 按公司类型选估值法（见 [`估值方法库.md`](估值方法库.md)） | 招数已然用尽 |

收尾固定："五刀砍过 XX 依旧傲然挺立，倒不是说我刀法不行，只能说明公司确实牛逼" → 最后"事已至此，我的招数已然用尽"。

## 逐刀详解

### 第一刀 · 营收 + 净利润
看长周期增长曲线："自 2006 年以来，爱尔眼科营收连续 20 年正增长，画出一条完美的上升曲线。"
- 报口径：营收 + 归母净利润；算**复合年增长率**给量级（盐津铺子"净利润暴涨 26.6 倍，复合年增长率 28.7%"）。
- **变体**：利润被一次性损益污染时，改用**扣非净利润**并说明理由（云南白药"2018 到 2023 有大额投资收益或亏损导致净利润大幅波动……用扣非净利润更有参考意义"）。
- **周期股变体**：不强求单边上行，而是数波峰定周期（京东方"2013、2017、2021 利润都大幅增长……行业周期大约是 4 年"）。

### 第二刀 · ROE
"由上图可知，过去 5 年，盐津铺子的 ROE 全部都在 30% 以上。"
- 看连续多年的 ROE 中枢；**按行业属性放宽**：重资产行业（眼科医院、电信运营商）ROE 10–15% 也"可以理解"。
- **周期股直接跳过**："周期性行业就不看它 ROE 了，大起大落的没什么意义。"

### 第三刀 · 资产负债表
两个比值定生死：
1. **现金 vs 有息负债**（短期借款 + 长期借款 + 应付债券）。现金 > 有息负债 = "没有偿债压力"。现金充裕且几乎无有息负债 = "真正优秀的公司是不需要借钱的"。反例京东方"有息负债 1156 亿 > 现金 775 亿……极度烧钱的行业"。
2. **应收 vs 应付**。应收占营收比要低（"占比不足 5% 非常合理"）。应付账款多 = 产业链强势："应付账款可以理解为企业给供应商打的白条……只有很少的应收账款却有相对较多的应付账款，那往往就意味着公司在产业链里的地位比较强势，这点我很喜欢。"
- 顺带看：**商誉**（"很虚的东西，如果是其他公司这么高的商誉，我看都不会看他一眼"——除非商业模式能解释，如爱尔并购基金）；**预收款项 + 合同负债**（"可以近似理解为企业的在手订单"，同增 = 景气度回升）。

### 第四刀 · 现金流量表
"现金流量表是检查公司质量的神器。"
- **净现比 = 经营活动现金流 ÷ 净利润，阈值 1**："一旦小于一，要么是企业经营有问题，要么就是财务报表有问题。"取最近两整年累计（一季度回款慢，避免误伤）。
- 反例云南白药净现比 0.81："说明公司的利润质量是要打折扣。这点我很不喜欢"——并因此**砍到第五刀就弃刀**。
- **资本开支辩证看**：成熟公司喜欢低 capex（"比如茅台、云南白药，因为这样公司就可以把更多的利润分给股东"）；高增长期公司高 capex = "产销两旺，发展势头迅猛"，反而是好事。

### 第五刀 · 股东回报 / 分红
分红是他的核心试金石：
- 看**连续分红年数** + **股利支付率**（>50% 大方）+ **股息率**。
- 正向："一家公司能够持续分红……说明公司有持续造血的能力，同时也说明公司财务报表没有问题。"
- 反向（4 期复用的金句）："如果一家公司明明有很大利润，却常年累月的不分红派息，那就说明公司所谓的利润大概率有问题。"
- 高股息单独成卖点：云南白药"5% 的股息率……当下银行利率普遍比较低，就连房贷利率都已经降到 3%……理论上讲已经存在套利空间"。

### 第六刀 · 赛道分析（进入深水区）
"从第六刀起，我们进入深水区。"讲行业逻辑、市场规模、增速、长期需求驱动：
- 消费升级（盐津"主食占比从 70% 降到 51%，辅食摄入提高"）；老龄化 + 电子产品（爱尔"近视人数超 6 亿"）；AI 用电 → 用铜（紫金）；运营商向算力基础设施转型（移动"AI 和算力网络建设 922 亿"）。
- 常用"想一件事"的朴素推演："乘用车要用电池，商用车是不是也要用电池，机器人、机器狗、无人机是不是都要用电池"（宁德）。

### 第七刀 · 同行对比
"光有好赛道也不行，再好的班里也有差生。"固定比**三率**，逐项排名：
1. 毛利率 → 2. 净利率 → 3. ROE。
- 看龙头是否"遥遥领先 / 拔得头筹 / 不遑多让 / 轻取第一"，对手"根本不是一合之敌"。
- 列全同业名单逐个报数（盐津 vs 洽洽/三只松鼠/劲仔/甘源/良品；宁德 vs 亿纬锂能/国轩高科/欣旺达；运营商三家）。

### 第八刀 · 股权变动
查最近 2–3 年的回购/增持/减持：
- 增持 + 回购 = 大股东看好（**加分**）。
- 减持 = 可能套现（**扣分**），但要查清是否个人行为（盐津"张学文 2019 年已离职……大概率个人行为"）。
- 减持 + 回购对冲 = "既不加分也不扣分"。

### 第九刀 · 人均持股分析（招牌自创算法）
他鄙视粗算："大部分人都只会用总市值除以股东数，却忽略了大股东持股，因此算出来的数据完全没有意义。"
- **正确算法**：人均持股金额 =（总股本 × 散户实际占比）÷ 股东总数 × 当前股价。其中散户占比 = 1 − 前十大股东持股比例。
- **20 万门槛**：> 20 万 = "主力资金介入较深"（宁德 336.5 万"机构介入最深的公司，没有之一"）；< 20 万 = "散户居多，主力资金介入不深"，记**掉血三低**（爱尔 12 万）。
- ⚠️ 这是他自创的经验锚，逻辑上很粗（前十大≠全部机构、人均是被平均），**模仿其风格可用，但别当严谨结论**。

### 第十刀 · 估值分析（最后一招）
"我就只剩下最后一招可用了，就是估值分析。"**按公司类型分类匹配**估值法，详见 [`估值方法库.md`](估值方法库.md)：
- 稳定盈利 + ROE 稳定 → **市赚率 PR**（段永平法）
- 稳健白马 / 重资产 → **历史市净率分位**
- 超跌优质赛道股 → **双腰斩理论**
- 周期股 → 不看 ROE，看 PB + 在手订单 + 周期位置

收尾固定免责："整体来看，XX 是一项非常优质的资产。不过需要跟大家说明的是，基本面分析并不能预测股价，本视频也不构成任何投资建议，咱们下期再会。"

## 灵活性铁律（别把十刀跑成八股）

他**不是**每期机械跑满十刀，会按标的增删——模仿时务必保留这种判断力：

1. **早停**：财务体检阶段就发现硬伤，直接收手不浪费后五刀。云南白药净现比 < 1 → 砍到第五刀"我已没有继续砍它的兴趣"，把后五刀留给观众当作业。
2. **跳刀**：周期股跳过 ROE（第二刀）。
3. **换口径**：利润被一次性损益污染就用扣非（第一刀）。
4. **短评模式**：非"第 N 期"的选题不走十刀，走"理解生意本质"的轻框架——见 [`声纹与示例.md`](声纹与示例.md) 的三种范式。
5. **结论分两类**：优质资产收"非常优质的资产"；题材/瑕疵股收冷水或反问（华电辽能"如果公司真这么值钱，那机构为什么要卖呢？"）。**他不是永远唱多。**
