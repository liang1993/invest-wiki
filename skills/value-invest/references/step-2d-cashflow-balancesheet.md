# Step 2D: 现金流与资产负债表质量深挖

> 详细子流程，由 SKILL.md 的 Step 2D 概要章节按需加载。对称于 Step 1B（利润表逐行分解）——1B 深挖利润表，2D 深挖现金流量表 + 资产负债表。

**目的**：AKShare 汇总只给"OCF/净利""资产负债率"裸评分，看不到现金流量表 / 资产负债表逐行。复杂现金结构（财务公司类金融子公司、合同负债大幅波动、大额趴账现金）的公司仅看裸评分会误读。本步骤建立真实现金生成基线 + 净现金口径，喂 Step 4 DCF（正常化 FCF）/ Step 6 安全边际（下行托底校验）。

**single source（不重复定义口径）**：OCF/净利含量、自由现金流、分红/FCF 覆盖度的**判据与门槛以 [`价值陷阱排雷.md` 第二层](../../../wiki/strategies/价值陷阱排雷.md)（line 75-111）为 single source**。本文件只做"个股化深挖 + 喂估值"，不另立口径。

**适用条件 / 跳过条件**：见 SKILL.md Step 2D「何时执行 / 何时跳过」。关键：**主业即金融（银行/券商/保险）跳过整套**（按 Step 0 企业类型判，不按"有无吸收存款科目"判）；**实业主业 + 财务公司子公司（如茅台）是核心目标，不跳过**。

## 口径契约（硬约束，防双重计算）

| 维度 | 口径 | 用途 |
|---|---|---|
| 四档锚点（合理价值/买入/减仓/清仓） | **含现金 PE** | 与个股历史 PE 中枢同口径，定锚唯一依据 |
| 净现金 / 扣现金 PE / 扣现金 EV | **辅助维度** | 判主业贵贱 + Step 6/8 事后托底校验 + 趴账折价/催化 |

> **硬规则（净现金只当安全边际，不抬估值）**：净现金/扣现金 EV **不进合理价值、不上调任何锚点或安全边际比例**——含现金 PE 已隐含现金价值，再加一次即重复计价。资本返还催化的"解锁价值"仅作独立的价值兑现路径叙事（公司明确启动大额返还时于催化章节单列，打 3-5 折），**同样不计入合理价值 / 四档锚点**。

## 2D.1 OCF-净利润勾稽 + 收现比 + 营运资本质量

**目的**：破除"OCF/净利 < 1 = 基本面恶化"的裸评分误读，定位现金与利润背离的真因。

### 数据提取（现金流量表 + 资产负债表，单位亿元）

```
| 项目 | T | T-1 | T-2 |
|------|---|-----|-----|
| 净利润 | | | |
| 经营活动现金流净额(OCF) | | | |
| 销售商品/提供劳务收到的现金 | | | |
| 营业收入 | | | |
| 应收账款 + 应收票据 | | | |
| 存货 | | | |
| 应付账款 + 应付票据 | | | |
| 合同负债(预收) | | | |
```

### 三个比率 + 趋势

| 比率 | 公式 | 健康区间（[价值陷阱排雷] single source） |
|---|---|---|
| 利润现金流含量 | OCF / 净利润 | 长期 ≈ 1.0 |
| 收现比 | 销售商品收到的现金 / 营业收入 | 含税口径通常 1.0-1.2，趋势比绝对值重要 |
| 营运资本占用率 | (应收+存货-应付) / 营业收入 | 看趋势，骤升=收入质量存疑/需求转弱 |

### 背离归因 checklist（OCF/净利 偏离 1.0 时逐项查）

1. **营运资本变动**：应收/存货骤增（占款）压 OCF；应付/合同负债增加（占用上游/下游）抬 OCF。
2. **合同负债 swing**：预收大降 = 下游停止预打款（需求侧预警，茅台 2026Q1 -65%）；这是**业务相关**的真信号，要保留。
3. **财务公司/类金融子公司存款流**：合并报表里财务公司"吸收存款"增减会直接扰动 OCF，**与白酒/实业主业现金无关**——必须剥离后再判主业。
4. **大额非现金项**：减值、SBC、公允价值变动。

> **茅台 worked example**：2025 OCF 615.22 亿（-33.46%），OCF/净利 = 615/823 = **0.75**（表观偏弱）。但年报 p.6 明确归因："主要是控股子公司财务公司吸收集团成员单位存款减少及不可随时支取的同业存款增加"——**是财务公司存款流扰动，非白酒主业现金恶化**。剥离财务公司后，白酒主业（经销商先打款、capex 极小）仍是现金机器。真正的业务预警是合同负债 -65%（归因 2），已计入合理 PE 下调。**裸评分会把 0.75 误判成基本面恶化——这正是 2D.1 存在的理由。**

## 2D.2 正常化 FCF + 分红覆盖

**目的**：给 Step 4 DCF 喂一个剔过一次性扰动的 FCF 基数（消除区间过宽）；同时验证分红可持续性。

### 正常化 FCF 公式

```
正常化 FCF = 正常化 OCF − 维持性 capex
  正常化 OCF = OCF − 一次性营运资本扰动 − 金融子公司现金流贡献/扰动
  维持性 capex ≈ 近 3-5 年折旧摊销均值（代理法，[估算] 标 confidence）
  扩张性 capex（超出折旧摊销的部分）不剔——它对应未来增长，由 DCF 的 g 承接
```

> **维持性/扩张性拆分是本步最易拍脑袋处**：年报不直接披露。用"维持性 ≈ D&A 均值"代理，并标 [估算] + 给区间。若公司处大扩产期（capex >> D&A），明确说明正常化 FCF 的不确定性。

### 分红覆盖度（[价值陷阱排雷] 判据）

```
分红 / 正常化 FCF 覆盖度 = 现金分红总额 / 正常化 FCF
  < 1.0 → 可持续
  > 1.0 → 借钱/动用存量分红，高分红陷阱预警
```

> **茅台 worked example**：正常化 FCF ≈ 780 亿（≈ 净利，capex 极小、固定资产仅 +2.8%；用 615 亿被扰动的 OCF 会低估）→ 喂 Step 4 DCF 当期基数。分红 350.33 亿（末期）/ 正常化 FCF 780 ≈ 0.45 < 1.0，分红可持续。

> **对照例：高分红陷阱（示意数据，非真实公司，仅演示 2D.1→2D.2 检测链）**
> 某高股息制造企业 X：净利 100 / OCF 60 → **OCF/净利 0.6**（3 年持续 < 0.85，触发条件 2）。
> - **2D.1 归因**：应收账款占营收比 3 年从 20% → 40%（营运资本占用骤升），收现比从 1.0 滑到 0.85 → **利润是"赊账赚的"，不是真现金**（红旗 1+2）。
> - **2D.2 正常化 FCF**：维持性 capex ≈ D&A 40 → 正常化 FCF = 60 − 40 = **20**；现金分红 26 → **分红 / 正常化 FCF = 26/20 = 1.3 > 1.0**（红旗 3：分红靠借钱/动用存量，不可持续，[价值陷阱排雷] 判据）。
> - **结论**：表观高股息（如对应 5%）看着诱人，但 OCF/净利 0.6 + 应收暴增 + 分红 1.3× FCF = 典型价值陷阱，股息不可持续 → DCF 的 FCF 基数取 20（非 OCF 60），且把"分红不可持续"写进风险章节。**与茅台对照**：茅台主业现金健康、分红/FCF 0.45，X 则三红旗齐发——同样"高股息"，一个是真现金回报、一个是会计幻觉。

## 2D.3 净现金口径

**目的**：算出真实可支配净现金，区分"自有现金"与"金融子公司负债"。

### 数据提取（**优先读年报合并资产负债表正表，非 MD&A 变动表**——后者会漏科目）

```
资产端（现金 + 类现金金融资产）：
  + 货币资金
  + 交易性金融资产 / 理财
  + 拆出资金（财务公司同业拆放 = 自有现金赚息）
  + 买入返售金融资产
  + 一年内到期的非流动资产（属财务公司债权投资部分）
  + 发放贷款及垫款（财务公司）
扣减项：
  − 有息负债（短期借款 + 长期借款 + 应付债券 + 一年内到期长期负债）
  − 金融子公司对外负债（吸收存款及同业存放 = 对集团成员负债）
  − 受限 / 质押货币资金（保证金、冻结，不可支配）
  − 少数股东归属（若现金在非全资子公司，按少数股东比例扣）
= 可支配净现金
```

> **金融子公司口径提醒**：拆出资金（资产，自有现金塞财务公司赚同业息）容易和吸收存款（负债，对集团成员）混。前者加、后者减，**净额才是股东现金**。

### 输出

净现金绝对额 + 净现金/股 + 占总资产% + 占市值%。

> **茅台 worked example（2025 年末，合并资产负债表正表 p.56-57）**：货币资金 516.91 + 拆出资金 990.96 + 一年内到期非流动 268.71 + 买入返售 88.80（附注9，**MD&A 变动表漏了此项**）+ 发放贷款 15.54 = **~1880.9 亿**；零有息负债（短期/长期借款、应付债券均空）；减吸收存款 180.38 → **净现金 ≈ 1700 亿 = 136 元/股（占现价 11%）**。（另有债权投资/其他非流动金融资产 ~87 亿未计入，故偏保守。）

## 2D.4 扣现金估值

**目的**：剔除现金及其收益，看经营主业本身的估值倍数。

```
扣现金 PE = (市值 − 净现金) / (净利 − 现金税后收益)
扣现金 EV/EBIT 同理（净利换 EBIT、市值换 EV）
```

> **分子分母同口径（硬规则）**：分子剔了净现金，分母**必须同时剔现金的税后收益**（利息收入 + 财务公司利息/手续费收入，税后），否则口径不对称、扣现金 PE 算虚低。**反推验证**：现金收益取 0 和取上限两端，看扣现金 PE 区间是否稳定。

> **茅台 worked example**：(市值 15851 − 净现金 1700) / (TTM 净利 827 − 现金/财务公司税后收益 ~25[估算]) = 14151 / ~802 ≈ **17-18x**，比表观 PE(TTM) 19.2x 低约 1-1.5x。现金收益 ~25 亿[估算] = 财务公司利息及手续费收入约 32 亿税前（营业总收入 − 营业收入）× 0.75；取 0~32 亿，扣现金 PE 均落 17.1-17.8x（对该估算不敏感）。**口径契约重申**：四档锚点走含现金 20x（与历史中枢同口径），扣现金 17-18x 只回答"主业贵不贵"，不改四档。

## 2D.5 净现金的双重角色

### ① 下行托底（喂 Step 6.6）

- **资产安全垫** = 可支配净现金/股 ÷ 当前股价（受限资金不算可支配托底）。
- **悲观价 EV 校验** = (悲观价 × 总股本 − 净现金) / (净利 − 现金收益) = 悲观情景下主业扣现金 EV 倍数。倍数已低 → 悲观价成色足。
- **硬规则**：仅事后校验，不上调悲观价/安全边际（见口径契约）。

### ② 趴账现金折价 / 催化

- **折价逻辑**：低收益现金（赚 ~2-3%）被表观 PE 按"低利息资本化"，等于低估其面值。低估额 ≈ 净现金面值 − 现金收益 × 表观 PE。
- **折价理由**：分红率未达 100% 仍留存滚存、部分在受监管财务公司 + 关联占用嫌疑、（国企）资本配置股东友好度。**不宜按面值加回，打 3-5 折**。
- **催化**：资本返还加速（特别分红 / 提分红率 / 加大回购）→ 市场按面值重估趴账现金 → 解锁 ≈ 净现金/股 × (3-5 折)。比"等股价跌到买入价"更现实的价值兑现路径。

> **茅台 worked example**：现金赚 ~2.7% 被表观倍数低估约 ~1100 亿（~88 元/股）；按 3-5 折，资本返还加速可解锁 ~40-70 元/股。下行：136 元/股净现金托底，悲观价 985 对应主业扣现金 EV ~13x，安全垫厚。
