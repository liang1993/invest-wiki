# 宏观边际变量追踪

> 追踪市场当前**主动重新定价的宏观边际变量**——不是数据本身，而是"市场此刻在博弈什么、哪个变量在边际上驱动 regime"。**用途**：[periodic-review](../../skills/periodic-review/) 每次复盘问一句"8 个主导变量里，哪个**跨了阈值 / 翻了方向**？"，只报 shift、不报噪音（契合"变化优先"哲学）。
> 与 [宏观仪表盘](宏观仪表盘.md) 互补：**仪表盘 = 原始数据时间序列**，**本页 = regime 解读层 + 信号灯**。

## 变量明细（边际逻辑）

**① 美联储利率路径 🔴**——2026 来首次 mid-cycle 路径反向（沃什首秀 SEP 从"降息"翻"加息"中位）。是当前全球估值重心的主驱动。**今日 risk-off 的统一根因**。
**② 美国通胀结构 ⚠️**——决定 Fed 是否真扣扳机的争议点：核心服务/住宅黏性 vs 油价输入性缓解的拔河。**5 月 PCE（6 月底发布）已印证黏性：核心 3.4% YoY（2023-10 来最高）/+0.3% MoM 跨 0.25% 监控阈、headline 4.1%**，能源分项 +4%/月仍是主因；9 月加息押注因 7/2 弱非农（+57K）降温、转两侧博弈。数据 in-line 无超预期，灯维持 ⚠️。
**③ 美元+美债 🔴**——对港股**最直接**的传导轴：10Y >4.5% → 外资 EM 机会成本升、港股 DCF 折现率升、HIBOR 随美元走高。叠加 BBB 财政供给（CBO 测 +$3.4T [观测 NBC/CBO]）抬期限溢价。
**④ AI capex / 美股集中度 ⚠️（6/26 由 🔴 降级）**——全球最大单一**股权**风险。6/23 急杀（KOSPI 熔断）次日即反弹，确认属**估值/仓位事件而非周期拐点**（详见 [AI硬件追踪](AI硬件追踪.md)，存储股崩但 DRAM/HBM 合约价无下跌）；但底层 ROI 背离担忧结构性加重（大厂 record capex vs FCF 同比大降）。转入高位监控，看点是 Q2 财报季（7 月下旬）capex 指引**是否首次下修** + HBM 合约价是否转跌。
**⑤ BOJ / 日元 carry ⚠️**——最宽的**尾部**风险（2024-08 剧本：BOJ 仅加 15bp 触发全球 carry unwind）。当前 USD/JPY 161 是日元弱（carry 未平），但美日利差快速收敛即触发。
**⑥ 美伊 / 油价 🟢→⚠️**——三个宏观变量（油价→通胀→Fed）的串联节点。去风险化延续但 60 天临时协议 ~8 月中 到期，签约落地悬而未决，破裂则油价/通胀压力回补。
**⑦ 中国财政托底预期 ⚠️**——A 股侧的**主驱动**。"供强需弱"坐实后，市场全在博弈 7 月政治局是否把财政加码到足以改变需求轨迹。**公报措辞是单一最核心指标**。
**⑧ 中国货币-信用-地产 ⚠️**——货币侧已见底（净息差约束），M1 回升是弱苗头但社融连降说明信用需求未起；地产二阶导（房价/链条底部）+ BSR 出清是结构慢变量。等财政接力。

## 对 A股 / 港股的传导

- **港股远比 A 股脆弱**：美元/美债/AI 三条线**直接**传导、**无**国内政策缓冲；CNH 走弱 + IPO 解禁筹码 + 外资撤 = 抛压叠加。同等美元冲击下港股更脆弱。
- **A 股有缓冲**：资本账户管制 + 央行宽松预期 + 财政对冲预期，相对隔离于日元 carry 与 AI 直接冲击。
- **结构一致利好**：**高股息红利（银行/电力/电信/煤炭）** 在"高美债实际利率 + AI 杀估值"双背景下是防御锚（focus 中**中移动/招商/平安**受益）；中游制造受益油价回落。

## 信号灯定义

| 灯 | 含义 |
|---|---|
| 🔴 | 该变量正在**主动恶化**风险偏好 / 已跨负向阈值 |
| ⚠️ | **博弈中** / 接近阈值 / 方向未定 |
| 🟢 | 暂稳 / 利好或中性 |

## 复盘节奏（periodic-review 用）

- **每次复盘**：过一遍 8 项，**只更新发生 regime-relevant 变化的**（信号灯翻转 / 跨阈值），在报告里高亮 shift；无变化的写"维持"不展开。
- **触发加密**：任一变量跨阈值（如 10Y 破 4.6% / USD/JPY 破 155 / 7 月政治局定调）→ 单独高亮并评估对 focus 的传导。
- **季度重检框架**：每季度审一次"8 个变量是否还是当前主导"——边际变量会轮动，主轴可能换（如从"Fed×AI"切到"中国财政×地产"）。
