## 二、关键判断

1. **南向失速是本页当前的核心信号**：2026-06 单月净买仅 **+271 亿**，为 2025 年月均 ≈1,171 亿（14,048/12，[推算]）的两成；最近一窗（6/25-7/2）已转负 −178 亿，且 6/29 出现单日 −103 亿的 ⚡ 级流出。2021 年以来南向年度净买（亿港元，EM 日序求和 [观测·转发源]）：4,544 → 3,863 → 3,188 → 8,079 → **14,048（2025 纪录）** → 3,010（2026 YTD@6/30）。
2. **AH 溢价低位削弱南向的估值动能**：7/2 盘中 **123.87**（[观测·转发源] 东财 push2 当日单次实测 f43=12387；源间歇未入快照 raw、不参与套档。最近官方月末值 **119.08**@2026-05-29，[恒指 Factsheet](https://www.hsi.com.hk/static/uploads/contents/zh_cn/dl_centre/factsheets/ahpremiumc.pdf)；五年走势区间约 116-158 [估计·图读]，Factsheet 无年度极值文本）。当前贴近中金指出的**"分红税安排下 125% 平价隐性底"**（[原文已核](https://finance.sina.com.cn/stock/marketresearch/2025-07-21/doc-infheqee5094050.shtml)）——溢价越低 = 港股相对 A 股折价优势越薄、对南向的估值吸引力越弱（此为本页设计逻辑 [推算]；中金原文对南向流入的归因是内地"资金盛+资产荒"，**未**直接建立南向×AH 关系）。估值吸引力弱化与南向失速互为印证。
3. **货币面处"新常态"而非危机区**：总结余 548 亿离三次历史地板（445-446 亿）有 20% 余量，1M HIBOR 2.79% 在常态带；利差 −87bp 未达套息压力档（−200bp）。但港汇贴弱方 93% 意味着**缓冲薄**——若利差再走阔，弱方保证触发 → 抽水 → HIBOR 上行的传导环随时可启动（2025-06 剧本，当时利差 ≈−350bp，[华尔街见闻](https://hk.finance.yahoo.com/news/7-85%E4%B8%8D%E9%81%A0%E4%BA%86-sofr-hibor%E5%88%A9%E5%B7%AE%E7%88%86%E8%A1%A8-%E5%A5%97%E5%88%A9%E4%BA%A4%E6%98%93%E7%8B%82%E8%BD%9F%E6%B8%AF%E5%85%83-074003625.html)）。
4. **交易面是三层中最强的一层**：5 日均成交 3,228 亿高于 2026-04/05 官方 ADT（2,535/2,929 亿，[HKEX 月报](https://www.hkex.com.hk/Market-Data/Statistics/Consolidated-Reports/HKEX-Monthly-Market-Highlights?sc_lang=zh-HK)）；卖空 ex-ETP 14% 中性。留意"缩量"是南向失速向交易面传导的确认信号。

## 四、联汇机制速查（为什么这几个指标构成一条链）

```
1M HIBOR − SOFR 利差走负（港元便宜）
  → 套息交易（借港元买美元）→ 港汇走向 7.85 弱方
  → 弱方兑换保证触发：金管局买港元卖美元（market_activities 抽水）
  → 总结余下降 → HIBOR 对流出敏感、被动上行 → 利差收敛（自平衡）
反向：资金涌入 → 7.75 强方保证 → 注资 → 总结余暴增 → HIBOR 趋零（2025-05 剧本）
```

- 对股市的含义：**总结余低位时，资金流出会直接放大 HIBOR 波动**（分母端折现率+融资成本），港股对外部冲击的缓冲变薄；总结余高位时相反。
- ⚡ 传感器：兑换保证是否触发**以 HKMA 日序 `market_activities` 字段非零为准**（官方干预记录本身），不盯汇率读数。

## 五、触发框架（只收 HKD 原生触发；美债/carry 阈值见[边际变量页](宏观边际变量追踪.md)不复述）

| 信号 | 条件 | 动作 |
|---|---|---|
| 货币面 🔴 | 总结余 <500 亿 或 1M HIBOR >4%（两子读数取紧） | 复盘高亮；港股/中概标的风险背景升级，核对 [系统性风险防御](../strategies/系统性风险防御.md) |
| 资金流 🔴 | 南向 5 日 <−200 亿，或连续 2 窗 <0 | 复盘高亮；与 AH 标签联判"动能衰竭 vs 恐慌流出" |
| 放量恐慌/自满 | 5 日均成交 >3,500 亿 ⚙ 且 VHSI >35 / <20 | 事件级 regime，单独成段分析 |
| ⚡ 兑换保证触发 | `market_activities` ≠ 0 | 1-2 周内必然传导 HIBOR，加密观察 |
| ⚡ 南向单日 \|净买\| >100 亿 | 日序回扫发现（回溯口径） | 记录进 §3.2 ⚡ 列 |
