## EPS 基线说明

小米报表利润口径复杂：

```
2025 全年（年报）
GAAP 归母净利润     416 亿
 - 投资 FV 变动/SBC 等 -24 亿
= 经调整净利润      392 亿  ← 市场共识口径
 - 投资收益等       ~-139 亿
= 核心经营净利润    ~253 亿  ← 纯主业经营利润

2026Q1
GAAP 期间利润       47.3 亿  [观测 PDF p.1]
 + SBC 14.1 亿
 - 投资 FV 变动     -4.3 亿
 + 收购无形资产摊销 0.4 亿
 + 投资者金融负债   6.1 亿
 - 所得税影响       -2.9 亿
= 经调整净利润      60.7 亿  [观测 PDF p.23]

→ Q1 摊薄调整后 EPS = 60.7 亿 / 26.45 亿股摊薄 = 0.230 RMB/股 = 0.250 HKD
→ 年化（×4，最差季线性） = 1.00 HKD/股摊薄
```

注意：Q1 是结构性最差季（EV 新老切换 + IoT 国补退坡 + DRAM 高位 + 缺旺季），不可线性年化。

- ✓ **手机收入企稳假设基本成立（修正）**：wiki v2 假设 2027E 手机收入 +4.2%（1,720 亿）= 隐含份额企稳。Q1'26 出货 -19.2% 主体是周期性（DRAM 涨价砍低端），DRAM 回落后低端可放量、全球第三基本盘稳固——**收入企稳假设站得住**。唯一需 value-invest 留意的是高端化天花板（华为回归），它限制的是手机**毛利率上行空间**（高端=高毛利），不是收入企稳——建议保守看待 2027E 手机毛利率（11-12% 而非更高）

**verdict（2026-05-28 二次修正后）**:
- **主体是周期性/政策性/主动战略（可修复，粗估 ~70% [估计]）**：DRAM/NAND 涨价（贯穿手机低端+IoT+EV 成本端，最大单一外因）+ IoT 国补退坡（政策周期）+ 主动战略（手机砍低端保利润 / EV 新老切换+产能爬坡）。这些随 DRAM 周期回落（预计 2027 后）+ 武汉产能投产 + 国补基数效应而修复
- **少部分是有限结构性约束（粗估 ~30% [估计]）**：(1) 手机高端化天花板（华为回归是唯一真结构性，当前限于高端，但华为千元机搭麒麟+鸿蒙，中端有外溢侵蚀风险）；(2) IoT 线下渠道短板（< 2%）；(3) 印度系统性受限。**但这 3 项都是"增长天花板/扩张慢"，不是"基本盘恶化"**——手机全球第三+海外稳健+IoT入口、EV 健康增长，基本盘稳固
- 注：70/30 是无法精确证伪的定性拆分，标 [估计]；核心结论是"周期为主、结构性有限"的方向，非精确权重
- **综合判断（估值叙事重估）**：经营恶化**主体是周期，不是结构**——但这**不等于"被低估该上修"**。更准确的框架是「全能挑战者 ≠ 统治者」：股价 61→28 腰斩，本质是**市场给"全能科技巨头"叙事去泡沫，不是基本面崩盘**。61 港元定价的是"手机+EV+IoT+AI 全能赢家"，28 港元定价的是"每个战场都是强力挑战者、但非统治者"的现实——手机高端打不过苹果华为、EV 规模打不过比亚迪、IoT 线下打不过美的格力、AI 闭源追不上第一梯队。**周期修复（DRAM 回落 / EV 爬坡）支持 28 不再深跌；但"挑战者天花板"是结构性的，不支持回到当年的全能溢价**。所以 **25 HKD（19x）是"周期底部 + 结构性天花板"的平衡点——既不该按结构性失败下修到 22-23，也不该因周期为主上修到 26-27**。
- **两类下跌的区分（这是本案最该记住的）**：小米 61→28 里，"基本面 -43%"是周期（会修复，不该让估值永久下移）、"全能溢价收敛"是叙事重估（即使基本面修复也回不到高估值）。两者叠加 = 跌得多但不该抄底搏反弹、也不该恐慌清仓，25 附近是合理中枢。
- **Q2-Q3 关键验证**：(a) DRAM 是否见顶（决定手机/IoT/EV 三块利润修复节奏）；(b) 武汉投产后 EV 月销能否爬向 5 万+（核心催化）；(c) 手机高端份额是否被华为继续侵蚀，尤其华为千元机麒麟回归是否向中端外溢（唯一真结构性风险点，若兑现则"挑战者"地位进一步承压）
- **⚠️ 分析偏差自省**：本 deep-dive 首版把 EV+手机的周期性/主动战略都误判为结构性恶化（verdict 一度"长期 70%"），经用户两轮 pushback + 数据核实修正为"周期为主"。教训：难看的当期数据要先归因（一阶原因：周期？政策？主动战略？），不能直接定性为结构性衰退（呼应 MEMORY"指标变化先追一阶原因"）

### 🔍 框架学习

本次新发现 / 暴露盲点（追加至 references/learned-frameworks.md）:
- **2026-05-28 小米**：拆"高端化"叙事时除了拆销量构成（v1 框架），还需查**与竞品的相对位置**——小米 17 销量 472 万看似爆款，但 < 华为 Mate 80 578 万 < iPhone 17 2,920 万，**绝对销量在头部"不及格"** 同样是高端化叙事失败信号
- **2026-05-28 小米**：性能旗舰类产品（SU7 Ultra 类型）的"6 个月生命周期曲线"是一个新模式——容量小的细分品类（50 万+ 性能纯电 < 10 万辆/年），首发 1-2 季靠粉丝盘子，半年后必然衰退到细分容量。**适用扩展**：所有"性能 / 高端 / 限量"型产品（奢侈品、潮玩限定款、限量电子产品）
