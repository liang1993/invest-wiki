# 拼多多 (PDD, 纳斯达克) 投资价值分析

> 首次建档：2026-07-28 ｜ 现价 **84.85 USD**（2026-07-27 收盘）｜ 触发原因：中概互联 ETF（513050）第三大权重 7.09%，此前无个股页
> 汇率口径：USD/CNY = **6.7928**（[观测] 央行中间价 2026-07-28）。人民币较 2025 年初约 7.25 已升值约 6%——这一点是本次估值的关键，见「利润桥」一节。
> 股本口径（**两套，不可混用**）：**摊薄 ADS 约 1,480M**（[推算] Q1'26 non-GAAP 净利 140.71 亿 ÷ 每 ADS 9.51 元 = 14.796 亿）用于 **EPS 与 PE**；**基本股约 1,424M**（[推算] 真实市值 $120.8B ÷ 现价 84.85）用于 **市值、净现金/股、ex-cash EV**。两者差约 3.9%（可转债 + 未行权股权激励），属正常摊薄，但计算时必须分开。用摊薄股算 PE-TTM = 8.78x，与行情商口径 8.7x 吻合。

## 业务结构 mapping

公司只披露两条收入线，这是本次建档最大的口径障碍：

```
PDD Holdings — 稀释 ADS 1,480M
├─ 披露口径（仅 2 条线）
│   ├─ 在线营销服务及其他  Q1'26 499 亿（47%）  +2.5%   ← 核心引擎在失速
│   └─ 交易服务            Q1'26 563 亿（53%）  +20%    ← 首次超越广告成为第一大收入源
├─ 实际经营单元（均无独立财务披露）
│   ├─ 主站（国内拼多多）—— 广告 + 佣金，利润发动机
│   ├─ Temu（跨境）—— 全托管 + 半托管/local-to-local
│   ├─ 多多买菜 —— 社区团购，佣金
│   └─ 新拼姆（2026-03 上海设立）—— 品牌自营，一期现金注资 150 亿，三年 1,000 亿
└─ 非经营资产：现金+短投 4,360.71 亿 RMB（$64.2B）= 市值 51%，**零分红零回购**
```

**分部拆分近似法（三法收敛，全部 [估计]）**：
1. 毛利率桥 [推算]：设 Temu 收入占比 s、主站/买菜混合毛利率约 76%、Temu 毛利率 g，则 `0.76×(1−s) + g×s = 0.558`（Q1'26 实际混合毛利率）→ g=10% 时 s=30.6%、g=15% 时 s=33.1%、g=25% 时 s=39.6% → **Temu 占比 33–40%，取中枢 35%**
2. 残差法：交易服务 563 亿 − 主站佣金约 160 亿 − 多多买菜约 105 亿 ≈ Temu 300–390 亿/季 → 年化 1,400–1,600 亿，与毛利率桥的 1,680 亿同量级
3. GMV 反算：Temu GMV $90–95B × take rate 20–22% ≈ $190–210 亿

→ **FY2026E 分部收入 [估计]**（合计 4,800 亿）：主站 2,700 亿（56%）｜Temu 1,680 亿（35%）｜多多买菜 420 亿（9%）

**经营利润桥 [推算]**：主站 OP = 集团 890 + Temu 亏 20 + 买菜亏 30 + 新拼姆亏 80 = **1,020 亿**（主站 OPM 37.8%）。反推验算：2024 集团 OP 1,079 亿 + Temu 亏 200 亿 + 买菜亏 50 亿 ≈ 主站 1,330 亿；1,330 − 千亿扶持年均 330 亿 = 1,000 亿 ≈ 1,020 亿 ✓ → **「千亿扶持」每年吃掉主站约 300–330 亿经营利润**。

### ⚠️ 核心发现：净利下滑是"线下"的，不是经营的

[推算] 利润桥（已反推验算）：
```
Q1'26: 196(OP) − 6.32(利息与投资) − 20.31(其他) = 169.37(税前) − 41.15(税) = 128.2
       vs 实际归母 125.47 ✓（差 2.7 亿为权益法/少数股东）
Q1'25: 160.7(OP) + 2.23 + 32.61 = 195.5(税前) − 44.81(税) = 150.7
       vs 实际归母 147.42 ✓（差 3.3 亿为权益法/少数股东，与 Q1'26 的 2.7 亿同量级）
非经营项同比摆动 = (−26.63) − (+34.84) = −61.5 亿
```

**经营利润 +22%、OPM +1.6pp，而归母 -15%——落差几乎 100% 由非经营项解释。** 主因是人民币升值（7.25 → 6.79）导致其美元资产的汇兑损失，叠加"其他收入"里政府补贴/增值税加计科目的正贡献消失。

**对 ADR 投资者的含义**：人民币升值压低人民币报表利润，却抬高人民币利润的美元折算值，在 ADR 层面**大体对冲**。因此按 USD 口径这 61.5 亿摆动应做正常化处理，**不应据此下修估值**。

> 反面平衡：有观点称"non-GAAP 也跌 17%，说明核心盈利实质下滑"——该推断不成立，因为 PDD 的 non-GAAP 只剔 SBC，并不剔汇兑/投资损益，同样含这 61.5 亿。

## 安全边际与买卖价

确定性 = **低**（≥3 项 -3x 级减分：国内竞争结构性 / Temu 关税与合规 / 零资本返还 + 分部零披露 / ADR-VIE），安全边际 35%、减仓 ×1.2、清仓 ×1.3。预期差调整 = 0（"预期已崩" -5% 与"核心引擎逼近失速" +5% 相抵）。

```
锚点A（固定折扣 35%）：64.4 = 99 × 0.65
锚点B（历史低位 PE 9x × TTM EPS 9.67）：87.0 → 受最低折扣 20% 封顶至 79.2 = 99 × 0.80
  → 有效锚点B = min(87.0, 79.2) = 79.2
→ 安全边际买入价 = max(64.4, 79.2) = 79.2 USD
锚点C（悲观情景）：69.3 = 99 × 0.7（仅展示，不参与定价）
减仓 = min(99×1.2 = 118.8, 历史高位 15x × 9.67 = 145) = 118.8 ｜ 清仓 = 99 × 1.3 = 128.7
```

> **TTM EPS $9.67 推导** [推算]：TTM 归母 = FY2025 994 − Q1'25 147.6 + Q1'26 125.47 = 971.87 亿 RMB ÷ 6.7928 ÷ 14.8 亿 ADS = $9.67。反推 PE-TTM = 84.85/9.67 = **8.78x**，与行情商口径 8.7x 吻合 ✓

**净现金下行托底（仅背书，不改锚）**：净现金约 $60.5B ÷ 基本股 1,424M = **$42.5/ADS = 股价的 50.1%**；当前 ex-cash EV = 真实市值 $120.8B − 净现金 $60.5B = **$60.3B** ÷ FY26E 税后经营利润 $10.2B = **5.9x**。市场对「主站 + Temu + 买菜」整体只给约 5.9 倍税后经营利润，下行资产垫极厚。（⚠️ 此处用**基本股/真实市值**口径，不能用摊薄股 1,480M×现价 = $125.6B 的虚高市值，否则倍数会被高估到 6.4x。）**但这是理论托底**——管理层不分红不回购，该现金本季还在亏钱，兑现路径依赖治理转向。

## 风险提示

1. **美国关税——2026-07-24 新增 12.5%（本估值基准日前 4 天，尚未进入一致预期）**：USTR 依 301 条款对 60 个经济体的强迫劳动调查加征，中国及中国香港适用 12.5%，与现行对华 301 关税叠加。Temu 全托管服装原税负堆叠已达 42.4%，叠加后升至约 **54.9%**。缓释：Temu 已转向半托管/local-to-local，关税由本地卖家承担，敞口结构性收缩。
2. **de minimis 已彻底终结**：EO 14256 自 2025-05-02 取消中国/香港 $800 以下免税；EO 14324 自 2025-08-29 扩至全球。Temu 赖以起家的中国直邮模式已失效。
3. **Temu 单位经济尚未跑通**：2024 年亏损 >200 亿；半托管在美欧 2026 年可望转盈，但全托管不行。**所有 Temu 财务均来自第三方渠道调研——公司零披露，无法独立核实。**
4. **主站货币化率失速 + 补贴无退坡时间表**：广告收入 +2.5% 创两年多新低，管理层在电话会上被直接追问却未正面回应、未给指引。
5. **治理与信息不对称**：$64.2B 现金零分红零回购且本季在亏钱；GMV、用户留存均不披露；「三年再造一个拼多多」无任何回报周期/IRR 披露。叠加 ADR-VIE 与退市尾部风险。
6. **竞争维度已转移**：即时零售（美团/淘宝闪购/京东秒送）成为新战场，**PDD 在此维度基本缺席**——这是广告增速失速的结构性解释。
