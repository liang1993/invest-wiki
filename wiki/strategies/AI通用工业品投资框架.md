# AI 通用工业品投资框架（commodity 视角）

**一句话**：如果 AI 大模型是可大规模复制的**通用工业品**而不是艺术品，那它的竞争规则、终局形态和估值方法，都该向**电厂 / 铝厂**对齐，而不是向移动互联网平台对齐。

本框架的价值不在于预测谁赢，而在于**换一个坐标系看 AI 投资**——它会把"谁的模型最强 / 谁用户最多 / 谁生态最全"这类问题降级，把"谁的单位成本最低 / 谁的产能约束最松"升级为主问题。

## 一、核心命题

> **AI 大模型厂生产的是可大规模批量复制的工业品，不是每轮迭代都不同的艺术品。**
>
> ⚠️ **归属**：这句话及其后的 commodity / 电厂 / 铝厂类比，是**解读者的归纳框架，不是梁文锋的措辞**——实录 52 条言论中**未出现**"电厂""铝厂""通用工业品""commodity"任何一个（PANews 全文核对）。梁文锋提供的是**素材**（成本排序、终局家数、拿不走大部分利润），把它组织成"AI = commodity"这个框架的是解读视频。框架好不好用要独立判断，不能借梁文锋的权威背书。

推论：不管它多高科技、多颠覆未来，只要产出物可大规模批量复制，它在产业链上的位置就等同于**电厂、铝厂**——全社会的基础要素供应商，而不是价值链顶端的分配者。

这个命题一旦成立，最重要的后果是：**移动互联网那套"抢用户 → 建生态 → 做超级 APP → 赢家通吃"的路径依赖失效。**微信、淘宝的护城河建立在用户习惯与社会关系的沉淀上，用户迁移要付出社交成本；大模型积累不了这种东西。

## 二、三条判据：怎么判断一个东西是不是 commodity

| # | 判据 | 在 AI 大模型上的表现 |
|---|---|---|
| **1** | **高度同质化** | 中铝的铝、俄铝的铝、美铝的铝本质无区别，只有质量和价格差异。客户不关心你过去用谁的铝，只关心现在谁的最好 |
| **2** | **强规模效应，单位成本定生死** | 规模越大单位成本越低，且与 scaling law 形成正反馈 |
| **3** | **零品牌溢价、零历史粘性**（限模型 / API 本身） | 买电买铝的人只看质量和价格，不看是谁生产的、也不看历史采购量。**范围限定**：这里说的是**模型本身可替换**，不包含客户为深度集成付出的沉没投入——后者显著 > 0，见 §六 推论 2 |

**判据的应用**：这三条是**可逐项证伪**的。任何一条持续不成立，本框架对该细分环节就不适用（见 §七）。

## 三、竞争规则：成本 > 时间 > 体验

实录给的排序：**成本第一 → 时间（效率）第二 → 用户体验第三**（原文对第三项留有"有些粘性和壁垒，但不本质"的余地）。

这是**成本效率驱动**的市场，不是用户需求驱动的市场。套巴菲特那句老话：**通用品行业里，行业最低成本是唯一的护城河。**

配套的一条更关键——实录原话是：

> 「**低成本是一个结果，我们的模型一直在架构上往更低成本走。**」（PANews 实录第 16 条）

> ⚠️ 解读视频把它转述为"低成本不是他们的商业模式，这是底层架构设计的结果"。意思相近但**不是原话**，本页采用一手表述。

这层意思给了一个可直接用的**尽调判据**：看一家模型厂降价，要分清它的低价是**架构挣出来的**还是**烧钱补出来的**。前者是护城河，后者是现金流黑洞。可观察的代理指标——毛利率能否在降价周期中保持稳定、单位 token 成本曲线的斜率、是否需要持续外部融资维持定价。

由此延伸出的几条反直觉推论（均来自实录）：

- 做 C 端产品、做多模态"只是一个功能"，不是现阶段模型厂该关注的主要问题
- 连 API 生意本身都不重视：「我只要搞几个人维护这个 API 就可以了，甚至客服都没有，也不用销售」——典型电厂思维，销售与客服成本占营收一两个点

## 四、终局：天然集中，但无法垄断

这是本框架最反直觉、也最有用的一对矛盾：

| 方向 | 机制 | 结论 |
|---|---|---|
| **会集中** | 规模效应 + scaling law 正反馈：规模越大 → 单位成本越低 → 越有能力扩大规模 | 实录判断「可能两家大公司、两家小公司就够了」 |
| **但垄不了断** | 产品同质化 + 能力持续趋同 + 无品牌溢价 + 转换成本低 | 活下来的几家在成本与效率上**永久厮杀** |

**「头部集中」与「拿不到垄断利润」同时成立** —— 这是理解后面所有投资推论的枢纽。对比记忆：**电力行业也高度集中，但没有一家电厂享受腾讯的利润率。**

## 五、投资推论（逐条标注来源）

> 本节每条都标明是**实录原话**、**实录的直接引申**还是**解读视频的引申**。三者可信权重不同，不要混用。

| # | 推论 | 来源 |
|---|---|---|
| 1 | **模型厂拿不走这轮产业革命的大部分利润。**电厂、铝厂、钢厂从来拿不走社会最核心的利润，薄利多销是宿命 | **实录原话**：「我绝对不认为大模型公司可以拿走（AI 行业的）大部分利润。」（PANews 第 31 条） |
| 2 | **国产替代的真实约束**：华为 950 超节点性能价格可完全平替 GB200/GB300，但**代价是四张华为卡顶一张英伟达卡、同时落后两年**，且**唯一瓶颈是产能不够** | **实录原话**（21经济网），解读视频漏掉全部三项约束，对 A 股最重要 |
| 3 | **看模型厂别看"谁最强"，看"同等能力下谁架构效率最高、单位成本最低"** ——能力领先是暂时的（同质化会吃掉它），成本领先才是结构性的 | 实录的直接引申（自"成本第一、时间第二"排序） |
| 4 | **真正的好商业模式在应用层**——被 AI 重构的千行百业，如同基于铝做飞机、基于电做电器 | ⚠️ **解读视频的引申**。实录只说了模型厂拿不走大部分利润（第 1 条），**没有说利润会流向应用层**——"拿不走"不等于"流向应用层"，也可能被算力上游、能源或客户剩余吃掉 |
| 5 | **中美大模型竞争的实质是"算力 → 供应链 → 训练效率"的综合成本效率比拼** | ⚠️ **解读视频的引申**。实录相关表述仅第 27 条「中美 AI 的差距主要在资源上」 |
| 6 | **最终胜出者可能不是有光环的公司，而是"下一个比亚迪 / 宁德时代"** | ⚠️ **解读视频的引申**。实录全文未出现比亚迪 / 宁德时代 |

> **第 4 条值得单独警惕**：它是整套框架里最常被引用、也最缺一手支撑的一环。"模型层不赚钱"是有原话的判断，"所以应用层赚钱"是解读者补上的。逻辑上二者之间缺一步——利润未必守恒地流到下游，也可能沉淀在能源与先进制程这类真正的瓶颈环节，或以低价形式让渡给终端客户。**把第 4 条当结论用之前，先问一句：凭什么是应用层？**

## 六、本页作者推论（⚠️ 非实录观点，独立成立性需自行验证）

以下是把上述框架往 A 股落地时的延伸，**实录中没有这些内容**，标注以便日后追责：

### 推论 1：若 commodity 命题成立，算力链应按周期股估值，而非成长股 ★

这是本框架对持仓最有指导意义、也最容易被忽略的一条。

**逻辑链**：commodity 行业的长期利润率向社会平均收敛 → 超额利润只出现在**产能紧张的窗口期** → 那么算力链的盈利本质是**产能周期函数**，不是**渗透率线性外推函数**。

按 [估值方法选择框架](估值方法选择框架.md) 的五分类，这意味着算力链应逐步从"高成长（PE / PS 主）"向"**真周期（PB 主，PE 仅作周期底参考）**"迁移。

**但必须配一个警告**：周期股在**景气顶部盈利最好、PE 最低**——这正是典型的价值陷阱形态，见 [价值陷阱排雷](价值陷阱排雷.md)。所以"该按周期估值"**绝不等于"现在该卖"**。实录自己说得很清楚：当前瓶颈是**产能不够**——产能紧张期恰恰是周期股赚钱最猛的阶段。

**正确的动作是换指标，不是换方向**：从跟踪"AI 渗透率 / 订单增速"改为跟踪**产能投放节奏、单位算力成本曲线、库存与交期**。这几个指标转向的时点，比 PE 高低有意义得多。可与 [去库存四阶段框架](去库存四阶段框架.md) 的阶段判别法联动使用。

**confidence：中**。主要不确定性在于——先进制程的产能扩张受地缘与设备约束，可能让"产能紧张"这个状态持续得比常规工业品周期长得多，从而在相当长时间里表现得像成长股。

### 推论 2：转换成本在深度集成层显著 > 0

实录侧强调转换成本低。但这在**API 调用层**近似成立，在**企业深度集成层**不成立：换模型供应商要重跑评测集、重调 prompt 与 agent 编排、重过合规审计。

**这条恰好补上了 §五 第 4 条缺的那一步**。"模型厂拿不走大部分利润"是实录原话，"所以利润流向应用层"是解读者跳过论证补的结论——而这层集成摩擦正是那一步论证：**壁垒长在集成里，不长在模型里**，所以能把摩擦转化成粘性的一方（应用层）才有条件留住利润。补上这一步之后，"利润流向应用层"才从断言变成有支撑的推论——但支撑它的是这条集成摩擦观察，不是梁文锋的权威。

**confidence：中高**（定性判断，缺乏公开的企业迁移率数据支撑）。

### 推论 3：这首先是一个"别买什么"的框架

框架的净效果是**降低而非提高**对 AI 产业链的估值容忍度：如果模型层与算力层最终都只赚合理利润，那么按永续高增长给出的定价就是错的。用它来做减法（识别哪些标的的估值隐含了不可持续的垄断假设），比用它来选股可靠。

## 七、可证伪信号：怎么知道这框架错了

框架不可证伪就是玄学。以下信号一旦出现，应下调本框架权重：

**证伪信号（commodity 命题不成立）**
- 某模型厂出现**持续可量化的定价权**：在竞品同质化的前提下毛利率长期扩张而非收敛
- **模型 / API 层**出现高转换成本的硬证据：在集成深度可比的前提下，客户迁移率仍显著低于价格差所隐含的水平。⚠️ 注意与 §六 推论 2 区分：**集成层**摩擦大**不**证伪本框架（模型仍是 commodity，摩擦长在客户侧的集成资产上）；只有**模型本身**变得难以替换才证伪。另：推论 2 是定性推断（confidence 中高），本条要求的是硬数据——两者认识论地位不同，不可互相引为证据
- 模型能力差距**重新拉开且不收敛**（判据 1 失效）
- 出现类似操作系统的**生态锁定**：应用层深度绑定单一模型厂的私有接口且难以抽象

**证实信号（commodity 化加速）**
- token 价格持续下行**且**头部厂商毛利率趋同
- 开源模型与闭源模型在主流任务上的差距持续收窄
- 国产芯片产能瓶颈缓解后，单位算力成本快速下台阶（对应实录的"唯一问题是产能"）
- 客户在价格差出现后**快速切换**供应商的公开案例增多

**关键待验证时点**：实录称"未来一年之内"（即 **2027-05 前**）可验证国产芯片生态完全可行。这是一个自带截止日的可检验断言，到期应回看本页。
