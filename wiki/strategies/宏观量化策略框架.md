# 宏观量化策略框架

> 把"对宏观的判断"**工程化**成可回测、可执行、跨资产的规则系统。核心不是"每次猜对方向"，而是把宏观拆成**状态概率**、靠数量积累概率优势；重心始终在**配风险**而非**猜收益**。
> 关联：[行业ETF动量轮动](行业ETF动量轮动.md)（信号+仓位层的 A 股落地）· [多因子模型与因子投资](多因子模型与因子投资.md)（因子原理）· [系统性风险防御](系统性风险防御.md)（风控层）· [宏观仪表盘](../macro/宏观仪表盘.md)（状态识别的数据输入）。

## ⚠️ 适用边界

- 本页是**方法论框架**，不是当下市场研判。具体 regime 判断与仓位随时变，写在 `journal/`，不进本页。
- **宏观状态样本极稀缺**（战后只十几轮完整周期）——这是它与股票多因子最根本的不同：别指望统计显著，**模型越简单越稳**。
- 个人可投标的/衍生品受限（做空、商品期货门槛高）→ 落地以 **ETF 多头轮动 + 现金/债避险**为主，而非 CTA 式全资产多空。
- 一句话定调：**收益预测廉价而脆弱，风险结构稳定而可靠**。所有方法都在为这句服务。

---

## 一、它赚什么钱 / 与相邻策略的边界

钱的**根本来源**：经济增长 + 通胀（货币条件）。可拆成四类能在股/债/商品/汇**同构构建**的跨资产风险溢价——`carry / trend / value / defensive`，彼此低相关、与股债也低相关，趋势在崩盘中还提供 "crisis alpha"（[观测] AQR《Value and Momentum Everywhere》）。

| 对比 | 宏观量化 | 相邻策略 |
|---|---|---|
| vs **CTA/趋势** | 含 carry、value、宏观状态判断，解读**基本面变化** | CTA 只追**价量趋势**（time-series momentum） |
| vs **股票指增/多因子** | **跨资产、含方向性**，追绝对收益 | 单资产类内**横截面选股**，追相对超额（阿尔法） |
| vs **主观宏观** | 覆盖几十上百标的、纪律化、可回测 | 聚焦 4-5 集中主题、靠判断、敢下重注 |

> 主观给**明确结论**（胜率高、下重注），量化给**模糊概率**（靠数量积累优势）。二者长期低相关，应**组合使用**而非二选一（见 §九 Man vs Machine）。

## 二、端到端 pipeline

```
数据 → 状态识别(内核) → 信号 → 组合构建 → 仓位/风控 → 回测验证 → 执行
```

| 环节 | 一句话定位 |
|---|---|
| 数据 | 全球+中国宏观、跨资产价格、文本；铁律用 **point-in-time / vintage** 数据 |
| 状态识别 | 把经济压成几个 regime，估"当前各状态概率"（§三，**内核**） |
| 信号 | 四类风格溢价 + 按象限给信号加权（§四） |
| 组合构建 | 把信号变权重，重心从猜收益转向配风险（§五） |
| 仓位/风控 | 波动率定仓 + 尾部/趋势刹车（§六） |
| 回测验证 | 防过拟合/前视/幸存者，walk-forward（§七） |
| 执行 | 期货/ETF/现金，分散下单、控换手成本 |

## 三、状态识别（内核——它区别于纯 CTA 的地方）

### 3.1 框架：美林投资时钟

用「增长 × 通胀」两轴切四象限，顺时针轮动（[观测] Greetham/美林《The Investment Clock》）：

| 象限 | 增长 / 通胀 | 占优资产 |
|---|---|---|
| 再通胀 Reflation | ↓ / ↓ | **债券** |
| 复苏 Recovery | ↑ / ↓ | **股票** |
| 过热 Overheat | ↑ / ↑ | **商品** |
| 滞胀 Stagflation | ↓ / ↑ | **现金** |

> 顺时针：债 → 股 → 商品 → 现金。注意**通胀方向**（很多二手资料把 Reflation/Recovery 写反）。硬伤是**实时定位极难**——产出缺口、通胀拐点都是事后才确认的滞后量，"时钟不告诉你现在几点"。这正是要上量化模型的原因。

### 3.2 从"硬指针"到"状态概率"：regime-switching

源头是 [观测] Hamilton(1989) Markov-switching。设离散状态按马尔可夫链演化，核心是**转移矩阵** `p_ij = P(s_t=j | s_{t-1}=i)`，观测分布条件于状态。关键输出是**滤波概率**递归（定义）：

```
P(s_t=j | 数据_t) ∝ 似然(y_t;θ_j) × Σ_i [ p_ij · P(s_{t-1}=i | 数据_{t-1}) ]
                  （上期各状态后验 × 转移 × 本期似然，归一化）
```

工程上常用 **HMM**（Baum-Welch 估参、Viterbi 求路径）或 **GMM/k-means**（去掉时间依赖的退化版）。HMM 滤出的 regime 概率可直接当**风控开关**（如只在低波态满仓）。

### 3.3 即时预测：nowcasting

核心是**动态因子模型(DFM) + 卡尔曼滤波**——大量参差、混频序列由少数共同因子驱动，递归估计并处理缺失。旗舰实现：[观测] Atlanta Fed **GDPNow**（动态因子补齐未发布数据 + 桥接方程，全程无主观调整）、[观测] NY Fed **Nowcast**（把每条数据"惊喜 news"× Kalman 权重，分解其贡献）。辅助：**MIDAS**（混频回归）、扩散指数 / 领先指标。

### 3.4 落地成"概率矩阵"

这是实践者口中"输出复苏/过热/滞胀/衰退概率矩阵"的真身（定义）：

```
当前状态分布  p_t = [P(复苏), P(过热), P(滞胀), P(再通胀)]   ← HMM 后验
一步前推      p_{t+1} = p_t · 转移矩阵E                       ← 显式传播不确定性
资产观点      ŷ = Σ_i p_i · (状态 i 下的资产偏好)            ← 按概率加权，不二选一
```

**好处**：天然表达不确定性、避免拐点处非此即彼的误判、平滑加权而非状态跳变带来的高换手。[观测] AQR 建议"先把当前 regime 分布与转移矩阵结合，再喂预测模型"。
> 实践者视角：陈鹏把这描述为"模型永远给一串概率而非明确结论，靠数量积累概率优势"（[观测] 厚雪长波访谈）。

## 四、信号层：四类跨资产风格

| 因子 | 直觉 | 跨资产构建（举例） |
|---|---|---|
| **趋势 TSM** | 涨的继续涨 | `sign(过去12月超额收益)`，做多正/做空负 |
| **Carry** | 价格不动时白拿的收益 | 债=收益率/曲线斜率、汇=利差、商品=展期收益、股=股息−融资 |
| **Value** | 便宜均值回归 | 股=B/P、债=实际收益率、汇=PPP 偏离 |
| **Defensive** | 低 beta/高质量长期跑赢 | 做多低 beta、做空高 beta（BAB） |

时序动量经 [观测] Moskowitz-Ooi-Pedersen(2012) 在 58 个跨资产合约验证：几乎每个都有正向可预测性、52/58 统计显著，**约一年后部分反转**，在**极端行情表现最好**。它是"发散型"交易——**胜率常低于 50%、靠盈亏比 >1 的少数大赢单盈利**（这正是"40% 胜率也能赚钱"的数学本质）。**状态判断（§三）决定在哪个象限给哪类信号加权**：复苏给股票动量加码、滞胀切现金/防御。

## 五、组合构建：从"猜收益"到"配风险"

均值方差(MVO)理论最优，实务却是 **"误差最大化器"**——对收益估计 μ 的微小误差极敏感、权重剧烈摆动。主流转向**不依赖收益预测**的风险方法：

| 方法 | 逻辑 | 缺陷 |
|---|---|---|
| **风险平价 ERC** | 各资产**风险贡献**相等 | 隐含押注低波动资产、依赖杠杆 |
| **All Weather**（桥水） | 不赌象限，对四种宏观环境**等风险**暴露 | 利率上行周期承压 |
| **Black-Litterman** | 均衡收益 + 主观观点贝叶斯融合 | 需设观点置信度 |
| **HRP**（López de Prado） | 层次聚类→递归等风险二分 | 聚类对噪声敏感 |

ERC 核心（定义）：风险贡献 `RC_i = w_i·(Σw)_i / √(w'Σw)`，令所有 `RC_i` 相等；资产不相关、夏普相近时退化为**逆波动率加权 `w_i ∝ 1/σ_i`**。[观测] 桥水 All Weather 把"等风险"用到极致——用杠杆把低波债券放大到股票级风险，对任何宏观意外都平衡。[观测] HRP 用聚类+递归二分**不需对协方差求逆**（病态/奇异时仍可用），样本外波动低于逆方差与朴素组合。

## 六、仓位 sizing 与风控

**波动率目标（最常用的仓位引擎，定义）**：
```
杠杆 = 目标波动率 / 已实现波动率
```
低波加杠杆、高波降敞口，利用"波动聚集 + 波动与收益负相关"。[观测] 实证（QuantPedia 综述）"所有风险调整比率均改善、回撤下降"。**你的 `etf-momentum` skill 已实现这一层**（`敞口 = min(1, 15%/已实现波动)`）。

**Kelly 仓位**（定义）：`f* = (bp−q)/b` 最大化长期几何增长；全 Kelly 回撤可达 50%+，实务用**半 Kelly**（保留大部分增长、方差大降）。

**风控三件套**：
- **相关性危机趋同**：最需要分散时分散最失效——崩盘时股跌→降息→carry 平仓→信用走阔同时发生，跨资产相关性趋于 1。这是 vol-targeting / 风险平价的共同软肋。
- **尾部凸性对冲**：深度虚值期权等，平时小幅 bleed、崩盘爆发式赔付，与传统分散互补。
- **趋势止损叠加层** + 盯"做错时少亏"：控制左尾单笔损失，而非追高胜率（[观测] 厚雪长波；落地见 [系统性风险防御](系统性风险防御.md) 与 [行业ETF动量轮动 §六](行业ETF动量轮动.md)）。

## 七、回测与验证（最容易自欺的环节）

- **过拟合 / 多重检验**：试得越多越易撞出假规律 → [观测] **Deflated Sharpe Ratio**（Bailey-López de Prado）按试验次数、偏度、峰度调高显著性门槛。
- **前视偏差 / 幸存者偏差 / walk-forward**：决策只用 point-in-time 数据；剔除退市标的会高估业绩；滚动样本外反复自证。
- **★ 宏观状态稀缺——致命陷阱**：战后只十几轮完整周期，**别把"4 次衰退"当大样本**。复杂 regime 模型在小样本子集里参数极不稳——这就是实践者强调的"宏观数据少、极易过拟合"。应对：状态数克制（通常 2–4 个 [估计]）、强先验/正则、宁用更稳的宏观数据也别直接在资产收益上挖 regime。

## 八、AI / LLM 层：现实进度

| 成熟度 | 能力 |
|---|---|
| **已落地** | 央行措辞鹰鸽打分、政策不确定性 EPU、新闻情绪——作为**外生特征**喂传统模型 |
| **半落地** | LLM 辅助 nowcasting、事件抽取触发风控 |
| **实验室** | LLM 自主资产配置 / 全自动交易 agent / 直接判 regime 下单 |

两条关键证据：[观测] BIS WP1294《用 LLM 分解宏观情绪》——"文本情绪指数提升简单模型预测力，捕捉传统数据未覆盖的信息"；[观测] arXiv 2407.00890——纯时序大模型"五个里仅两个能打平 AR 基准、三个（含表现最好的 Moirai）含训练集污染、偶发离谱预测"。

> 翻译成实践者的话：AI 的增量在于**"会读文字"**（同样地缘冲突，能拆出"俄乌后黄金涨 vs 伊朗后黄金跌"背后市场状态不同），不在于"换个更大的预测器"；而"数字虚拟人选股"卡在**一致性 + 知识截断泄漏 + 黑箱不可控**，仍停在实验室（[观测] 厚雪长波）。**核心模式：AI 当"文字→结构化特征"的翻译器，决策留在可解释的计量/优化层，别让 LLM 直接拍板。**

## 九、机构标杆

- **桥水**：奠基 alpha-beta 分离 + risk parity，内核是"经济机器"因果框架；All Weather（不择时、四环境等风险）+ Pure Alpha（30-40 条**不相关**头寸）。
- **AQR**：value / momentum / carry / defensive 四风格做成多空、市场中性，跨五大资产组。
- **Man AHL / Winton / Aspect**：同源 1987 AHL，系统化趋势跟随起家，edge 在持续 R&D。
- **★ 反共识实证**（[观测] Harvey et al.《Man vs. Machine》2017）：1996–2014，经波动与因子调整后**系统化与主观的 appraisal ratio 相近**——"算法厌恶"无实证依据。结论不是谁更优，而是**两者低相关、应组合使用**。

## 十、中国市场特性（别照搬美式框架）

- **社融-流动性是主线**：2012 年后信贷指标失效，**社融同比成为 A 股更有效的领先指标**；"流动性是宏观最敏感变量"在 A 股尤其成立。
- **政策驱动 > 经济周期**：投资时钟在中国常背离，需本土化为「经济景气(PMI) + 通胀(核心 CPI) + 政策先行(社融/专项债) + 结构」四维。
- **标的与衍生品受限** → 个人更适合 **ETF 多头轮动 + 现金/债避险**，而非全资产多空。

## 十一、个人可复刻的最小路径（你已走到第 2–3 步）

```
1. 状态层：美林时钟简化版  → PMI(增长) × CPI(通胀) 四象限 → 股/债/商/现金
2. 信号层：跨资产/行业 ETF 6-12 月动量 + 200 日趋势过滤   ← etf-momentum 已实现
3. 仓位层：波动率目标，低波加仓/高波降仓                    ← etf-momentum 已实现(vol-targeting)
4. 概率层：hmmlearn 在(社融增速、利率、波动率)上拟合 2-3 个 regime，用状态概率调大类权重
5. 文本层(最后加)：EPU + 央行措辞 + 新闻情绪，当"风控阀门"，不当择时器
```

| 环节 | 工具（Python） |
|---|---|
| 取数 | `akshare` / `Tushare` / `fredapi` |
| 状态识别 | `hmmlearn`（regime 概率） |
| 组合优化 | `Riskfolio-Lib` / `PyPortfolioOpt`（含 HRP / Black-Litterman） |
| 回测 | `vectorbt` / `bt`（资产配置月频再平衡） |

> **对你而言，"宏观量化" = 在现有 `etf-momentum`（动量+vol-targeting）之上叠一个状态层**：用社融/PMI/CPI 的 regime 概率，动态调整组合的"股/债/商/现金"大类权重。第 4 步（HMM regime → 调权）是最自然的下一个增量，可与 [宏观仪表盘](../macro/宏观仪表盘.md)、[系统性风险防御](系统性风险防御.md) 直接对接。
> **纪律**：前 3 步用确定性规则跑通并回测稳健，再逐步加状态/文本层；文本信号永远当"特征/风控阀门"，决策留可解释层。

## 诚实的边界

1. **宏观状态稀缺是硬约束**——别指望统计显著，模型越简单越稳；这是它和股票多因子（海量样本）最不同处。
2. **AI 现在只在"读文字→特征"这一环真正加分**，自主决策仍不可托付（学术与实践者判断一致）。
3. **重心永远是配风险，不是猜收益**——MVO 那种"算准收益就赢"的直觉在这里是陷阱。
